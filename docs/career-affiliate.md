# 転職サービスへの導線（アフィリエイト）の運用

2026-10-17 開始。コードは `src/lib/career-links.ts` と `src/components/CareerCTA.tsx`。

## 何のための導線か

講座広告（`affiliate-links.ts`）は「これから受ける人」向けで、合格した人には出せるものが無かった。
合格した人・模試で合格圏に入った人の次の行動は「資格を仕事に活かす」なので、その先に転職サービスを置く。
講座の成果（申込・資料請求）とは別の財布で、合格者が増えるほど伸びる。

## いまの状態

**リンクが1本も入っていないので、どの面にも何も出ていない。** ASP で提携してリンクを貼った時点で点灯する。

| 面 | 出る条件 | placement |
|---|---|---|
| コラム末尾（講座広告のあと） | 資格の価値・使い道を扱う35本（`-iminai` / `-toha` / `-shukatsu` / `-meritto` / `-katsuyou`、`soumu-jinji-shikaku`） | `column_career` |

| 合格報告の送信後 | 「合格」を選んだ報告のときだけ1行 | `pass_report_career` |

## リンクの貼り方

1. ASP の管理画面で、掲載サイト＝シカクモン（shikakumon.com）として広告リンクを発行する。
   **生成されたリンクは改変しない**（既存リンクの a8mat から自前で作らない方針は講座広告と同じ）。
2. `src/lib/career-links.ts` の該当 track に `offer` を足す。

   ```ts
   kanri: {
     name: "…",
     headline: "…",
     body: "…",
     offer: {
       href: "https://px.a8.net/svt/ejp?a8mat=…",   // 発行されたリンクそのまま
       label: "（サービス名）で管理部門の求人を見る",
       pixel: "https://www…a8.net/0.gif?a8mat=…",     // 素材に付いていれば
     },
   },
   ```

3. A8 の場合は `src/lib/affiliate-program.ts` の `A8_PROGRAM` に、a8mat の第2区画と広告主名を1行足す
   （足さないと GA4 の `program` が `a8` のままになる）。
4. `npm run build` が通ることを確かめてデプロイ。デプロイ後に1回クリックして、着地と ASP 側のクリック計上を確認する。

## 掲載の注意

- **広告主の掲載ルールを先に読む。** 転職サービスは「年収が上がる」「必ず内定」などの表現や、
  特定の文言を禁止していることが多い。`career-links.ts` の `body` は特定サービスの効果をうたわない文にしてあるが、
  広告主から指定のある場合はそちらに合わせる。
- **成果条件をサイトに書かない**（「登録だけで OK」など。A8 は成果条件の公開を禁止している）。
  商標キーワードでのリスティング広告も多くの案件で禁止。
- 対象年齢・地域・経験の条件がある案件（「20代限定」「首都圏のみ」など）は、条件を `label` か `body` に書く。
  条件外の人の登録は否認されやすく、読者にとっても無駄足になる。
- 層の本文に事実（設置義務など）を書くときは、コラムと同じく出典を確かめてから。
  いまの本文の設置義務は、貸金業法（営業所ごとの貸金業務取扱主任者）、賃貸住宅管理業法（事務所ごとの業務管理者）、
  マンション管理適正化法（事務所ごとの管理業務主任者）。

## 効果の見方

GA4 の `affiliate_click` を `placement` の接尾辞 `_career` で絞る。`course` は `career-<資格ID>`（横断記事は `career-kanri`）。
`cta_impression` と同じ切り口で割れば面ごとのクリック率が出る。成果は ASP の管理画面で、プログラム別に見る。
