シカクモン（https://shikakumon.com）で、A8.net の「介護JJ」の掲載URLを登録してください。

## 守ること
- 変えてよいのは、介護JJの「広告掲載URL管理」への URL の追加だけ。提携の申請・解除、サイト情報・口座・プロフィールは変えない。
- px.a8.net で始まるリンクはクリックしない。介護JJ本体には登録しない（本人の申込は提携解除になる）。
- ID・パスワード・メールアドレス・口座情報・氏名を報告に書かない。
- 見つからない・読み取れないときは推測で埋めず「未取得（理由）」と書いて次へ進む。
