# Cowork に渡すプロンプト（転職サービスの提携申請とリンク発行）

2026-10-17 作成。転職導線の受け皿（`src/lib/career-links.ts`・`CareerCTA`）は入れたが、ASP のリンクが無いので何も表示されていない。
開発環境（クラウド）からは A8 の管理画面に入れないので、提携の確認・申請・リンク発行を Cowork に頼む。
下の枠の中をそのまま Cowork に貼る。

- 1回目（枠1）: 候補の条件の読み取り、提携申請、即時提携ならリンク発行。
- 2回目（枠2）: 審査待ちが承認されたあと、リンクを発行する。
- 3回目（枠3）: 開発側でリンクを貼って本番に出したあと、表示・遷移・計測を確かめる。

候補の出し方と根拠は `docs/career-affiliate.md`。結果が届いたら、開発側で `career-links.ts` の `offer` と
`affiliate-program.ts` の `A8_PROGRAM` にリンクと広告主を足す。

## 枠1: 条件の確認・提携申請・リンク発行

```
シカクモン（https://shikakumon.com）に、資格を活かした転職サービスへのアフィリエイト導線を入れます。
A8.net などの ASP で、転職サービスのプログラムの条件を確かめ、合うものに提携申請し、すぐ提携できたものはリンクを作ってください。

## サイトについて（判断の材料）
- シカクモンは資格試験の無料問題集サイト。読者は資格の学習者と合格者。
- 転職の導線を出すのは3か所: 資格の価値・使い道を扱うコラムの末尾、模擬試験で合格圏だった人の結果画面、合格報告を送った人の画面。
- 資格ごとに読者層を分けて、層ごとに1本のリンクを出す:
  管理部門（個人情報保護士・マイナンバー実務検定・ビジネス実務法務検定・知的財産管理技能検定・ハラスメントアドバイザーなど）、
  IT（ITパスポート・情報セキュリティ管理士・DXパスポート）、金融（貸金業務取扱主任者）、
  不動産（賃貸不動産経営管理士・管理業務主任者）、介護・福祉（社会福祉士・福祉住環境コーディネーター）、教員（教員採用試験）、
  総合（上の層にリンクが無いときの代わり。全資格に出る）。

## 守ること
- 変えてよいのは「B. 提携申請」と「C. リンク発行」だけ。対象は下の表のプログラムだけ。それ以外の画面は見るだけ。
- ASP の新規会員登録はしない。アカウントが無い ASP は「アカウントなし」と書いて次へ進む。
- ASP のサイト情報・口座・プロフィール・メディア登録の設定を変えない。提携の解除もしない。
- **転職サービス本体には登録・申込をしない**（多くの案件で本人の申込は禁止。成果の否認や規約違反になる）。
- 作ったリンクはクリックしない（クリックの確認は本番公開後に別に頼む）。
- ASP や広告主の文章・画像を報告に丸ごと写さない。金額・条件・禁止事項は短く書き取ればよい。
- ID・パスワード・メールアドレス・口座情報・氏名を報告に書かない。
- 画面が見つからない、表記が読み取れないときは推測で埋めず「未取得（理由）」と書いて次へ進む。

## B. 提携申請（変更してよいのはここと C だけ）
次をすべて満たすプログラムにだけ申請する。サイトは「シカクモン（shikakumon.com）」を選ぶ。
1. 資格・学習サイトへの掲載が禁止されていない。
2. 対象者の条件が狭すぎない（「首都圏のみ」「特定職種の経験者のみ」は申請しない。ただし UZUZ の「20代」は申請してよい）。
3. 申請に追加の書類・審査用の説明文の提出が要らない（要る場合は申請せず、何が要るかを報告する）。

申請の優先順（上から。条件を満たさなければ飛ばす）:
1. MS Agent（管理部門）
2. doda かマイナビエージェントのどちらか一方（総合。年齢条件が無く、成果条件が軽い方）
3. 社内SE転職ナビ（IT）。満たさなければマイナビITエージェント
4. マイナビ金融エージェント（金融）
5. UZUZ第二新卒（総合の20代向け）
6. 不動産・介護・福祉・教員: A の A8 の検索結果から、層ごとに1件（多くても2件）申請する。選ぶ基準は
   (1) 読者に合う（不動産は賃貸管理・マンション管理・宅建の求人を扱う、介護・福祉は介護職・相談職の求人を扱う、教員は教員・講師の求人を扱う）、
   (2) 対象者の条件が狭すぎない、(3) 成果条件が軽い（会員登録 ＞ 面談 ＞ 来社）、(4) 報酬が高い、の順。
   宅建Jobエージェント・かいご畑が A8 にあれば優先する。
7. A8 で不動産・介護の案件が1件も見つからなかったときだけ、もしもアフィリエイト・アクセストレードにアカウントがあれば、
   そちらで宅建Jobエージェント・かいご畑に申請する。

## C. リンク発行（即時提携できたものだけ）
提携済みになったプログラムで、サイト「シカクモン（shikakumon.com）」のテキストリンクを1本ずつ作る。
- クリック用の URL と、表示計測用の 1×1 画像の URL の両方。
- 着地はサービスのトップ。管理部門・IT・金融など、層に合う求人ページを着地に選べる場合は、そのページのリンクも1本作る。
- リンクは改変せず、管理画面に表示されたとおりに報告に書く。

## 報告の形
1. プログラムごとの表: 層／サービス名／ASP／提携の状態（申請した・即時提携・審査中・申請せず（理由）・アカウントなし）／
   成果条件／否認条件の要点／報酬／対象者の条件／掲載のルール（禁止表現・必須表記）／作ったリンク（クリック用・画像）。
   期待値がある項目は「期待値／実際／一致か」の形で。
2. A8 の検索結果（教員・介護・不動産・金融）の一覧。
3. 最後に箇条書きで: 期待値と違ったもの、申請しなかったものとその理由、サイトの文言で気をつけること（禁止表現・必須表記）。
```

## 枠2: 審査待ちが承認されたあとのリンク発行

```
シカクモン（https://shikakumon.com）の転職サービスのアフィリエイトで、前回申請したプログラムの審査結果を確かめ、承認されたものはリンクを作ってください。

## 守ること
- 新しい提携申請・解除、サイト情報・口座・プロフィールの変更はしない。転職サービス本体には登録しない。
- 作ったリンクはクリックしない。ID・メールアドレス・口座情報・氏名を報告に書かない。

## やること
1. A8（アカウントがあれば、もしもアフィリエイト・アクセストレードも）で、前回申請したプログラムの提携の状態を確かめる。
2. 承認されたプログラムで、サイト「シカクモン（shikakumon.com）」のテキストリンクを1本ずつ作る（クリック用 URL と 1×1 画像の URL）。
   層に合う求人ページを着地に選べる場合は、そのページのリンクも作る。リンクは改変せず、表示されたとおりに書く。
3. 否認されたプログラムは、理由が表示されていれば短く書く。

## 報告の形
プログラムごとに: サービス名／ASP／状態（承認・否認・審査中）／作ったリンク（クリック用・画像）／否認の理由。
```
