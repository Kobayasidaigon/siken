```
シカクモン（https://shikakumon.com）の GA4 で、キーイベントを1つだけ足してください（studio_click）。

## 守ること
- 変えてよいのは「管理 → データの表示 → イベント」の画面の「キーイベント」タブにある、studio_click のマークだけ。ほかのキーイベント・イベントの作成や変更・カスタム定義・データ保持・リンク・ユーザーは変えない。
- 対象は GA4 プロパティ 537254382（表示名は「https://shikakumon.com/」、データストリーム名は「シカクモン」）だけ。姉妹サイトのプロパティは触らない。
- 画面が説明と違う、イベントが一覧に無いなど、迷ったら変更せずに「未実施（理由）」と書いて終える。
- メールアドレスや氏名を報告に書かない。

## やること
1. GA4 のプロパティ 537254382（表示名「https://shikakumon.com/」）を開く。開いた Google アカウントに無ければ、ログイン中のほかのアカウントに切り替える。
2. 変更の前に、管理 → データの表示 → イベント の画面の「キーイベント」タブを見て、いまキーイベントになっているイベント名をすべて書き留める（affiliate_click と purchase）。
3. studio_click をキーイベントにする。
   - 同じ画面の「最近のイベント」タブに studio_click があれば、その行のスターを押してキーイベントにする。
   - 一覧に無ければ、「キーイベント」タブの「新しいキーイベント」でイベント名に studio_click（小文字・アンダースコア、綴りはこのとおり）を入れて保存する。
   - 「カウント方法」を選べる場合は「イベントごとに1回」（既定）のままにする。
4. purchase は GA4 が最初から決めているキーイベントで、マークは外せない（スターが押せない）。触らずにそのままにする。
5. affiliate_click はそのまま（キーイベントのまま）にする。
6. 変更のあと、もう一度キーイベントの一覧を見て、並んでいるイベント名をすべて書き留める。

- 実施した日時（日本時間）:
- うまくいかなかったこと・画面が説明と違ったこと: （無ければ「なし」）
```
