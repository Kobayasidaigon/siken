## 守ること
- すべて見るだけ。X には投稿しない（投稿画面を開いて、プレビューを見たら閉じる）。
- サイトや公式サイトの文章を丸ごと写さない。日付・条文番号・数値などを短く書き取ればよい。
- ID・パスワード・メールアドレス・氏名を報告に書かない。
- 見つからない・読み取れないときは推測で埋めず「未取得（理由）」と書いて次へ進む。

## B. 10問の中身の確認
問題は GitHub で読めます（リポジトリは公開）。各問題のページ:
https://github.com/Kobayasidaigon/siken/blob/claude/loving-tesla-khe7af/src/content/chizai/<問題>.md
（例: …/src/content/chizai/chizai-034.md）。ファイルの上に問題文・選択肢・正解の番号（correctAnswer）、下に解説があります。

chizai-034 通常実施権／chizai-035 特許権の譲渡／chizai-077 出版権／chizai-078 著作権侵害への対応／
chizai-095 意匠権侵害の救済／chizai-106 先願主義（商標法）／chizai-135 優越的地位の濫用／
chizai-145 実用新案から特許への変更／chizai-154 マドリッド協定議定書／chizai-184 特許分類

問題ごとに次を確かめる:
- 正解の選択肢が正しく、ほかの3つが誤りか（正解が1つに決まるか）。
- 解説に出てくる法令の条文・数値（期間・年数・件数など）が、A-2 の基準日の時点の原文と合っているか。
  原文は e-Gov 法令検索（https://laws.e-gov.go.jp/）、特許庁・文化庁・公正取引委員会・WIPO の公式のページを見る。
- 最近の改正（特許法・意匠法・商標法・著作権法・独占禁止法など）で古くなっていないか。
報告は問題ごとに1行: 問題／判定（問題なし・要修正・判断つかず）／理由（どの選択肢・どの条文・原文の値）／見た原文の URL。
