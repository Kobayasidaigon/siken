## 3. 分かっていること（要点）
1. 本体は「Google × 過去問コラム」で90日にセッション11倍。入口はほぼ「〇〇 過去問」検索。過去問が非公開のIBT/CBT試験（福祉住環境2級など）で特に強い。
2. **利用者は職場PCの社会人。** Edge 1位・デスクトップ58%（Bingではデスクトップ99%）、ACOM・Teams・Edge新規タブからの流入、土日は平日の半分。
3. **ほぼ全員が一見さん。** 新規率98.7%、学習履歴ページ到達5.8%、試験日登録6人。戻る仕組みがない。
4. **Studio への導線が細い。** 本体からのクリック 19人/6,332（0.3%）。LPのサンプル資格（ITパスポート/FP/簿記/宅建）が本体の主要資格（福祉住環境・個情保・知財・貸金）と一致しない。/pricing 滞在13秒。
5. **表示されているのに押されないクエリ**がGoogle・Bing両方にある（「福祉住環境コーディネーター2級」2,281表示/16クリック、「貸金 試験日」315/0、Bing の貸金・管業コラム 0.6%）。Bing自身が「メタディスクリプションが短い」「IndexNow未送信」を指摘。
6. **Copilot の引用が急増**（60日16,400件、9月は1日900件超、引用シェア30〜50%の質問あり）。引用元は「合格率・勉強時間・試験日」コラム。ただしクリックには繋がっていない（copilot経由 54セッション/90日）。
7. 収益に直結しているのは今のところアフィリエイト側（`affiliate_click` 257人/90日、主にユーキャン）。Studio は有料1人。
8. 競合: 資格問題ドリル（法人、27資格・11,179問、「根拠つき無料問題」と同じ訴求）、資格道場（123資格・47,478問）。量では勝てない。

## 4. 戦略（負けないための方針）
**クローンに真似できないのは「戻ってくる人」「使われて溜まるデータ」「名前」。今はこの3つがほぼゼロなので、ここを先に固める。**

5つの堀
1. **リピートの仕組み**（試験日設定 → 毎朝3問プッシュ／メール → 履歴同期）。ページはコピーできても登録済みの人は移らない。
2. **利用データをコンテンツにする**（みんなの正答率、間違えた人が多い問題TOP10、正答率データ付きコラム）。トラフィックがある側にしか作れない。
3. **信頼の見える化**（出典条文・最終確認日・法改正対応・正誤報告・運営者の顔）。競合の「根拠つき」の一段上に行く。
4. **領域を絞る**（過去問非公開のIBT/CBT試験、東商検定系、企業が取らせる資格）。広く浅い競合と同じ土俵に乗らない。
5. **名前で来る人を増やす**（通知、共有カード、コラム冒頭にサイト名＋数字 → AI回答に固有名詞が乗る）。

収益の見立て
- 短期: アフィリエイトを「決める瞬間」に移す（模試の結果画面、勉強時間／独学vs講座コラム、試験日6〜8週前）。資格ごとに講座を変える。
- 中期: Studio の売りを「AIが問題を作る」から **「本体で解いた履歴の同期＋忘却曲線＋弱点＋リマインド」** に変える。課金は「試験日までの買い切り」も試す（学習期間は1〜3ヶ月）。

## 5. いまやると決めた3本柱（横展開込み）
1. **決める瞬間に CTA** — 模試／本番形式の結果画面を「講座（アフィ）／弱点だけ復習（Studio）」の分岐点にする。得点帯で出し分け、文言はその人の数字を使う。
2. **リピートの仕組み** — 試験日ワンタップ設定 → 毎朝3問プッシュ（Studioのpush流用）／メール（＝Studio登録）→ 履歴同期。
3. **利用データをコンテンツに** — 全サイトの回答ログを Studio に集め、正答率・TOP10 を表示。**収集は表示より先に、今週中に全サイトへ。**

実装方針: 共通 `growth-kit`（結果画面パネル・試験日チップ・プッシュ・正答率バッジ・サイト別履歴アダプタ）を1つ作り、4サイトは組み込むだけ。データとアカウントは Studio に集約。

展開順: 本体 → 設備（GA4設置と同時）→ 衛生 → 筋トレ。

## 6. 並行して進める施策（レポートより）
- 資格名・「難易度」「試験日」クエリを受ける **試験ガイド記事**（福祉住環境2級・個人情報保護士・知財3級・貸金）＋ 貸金／管業コラムのメタディスクリプション書き直し
- 「試験日・合格率・勉強時間」コラムに **その場で1問** を埋め込む（情報を見に来た人ほど1問触ると始める）
- Studio LP の TRY IT サンプルを本体の主要資格に差し替え、`/pricing` は登録後に見せる

- Copilot 対策: 引用されるコラムに「シカクモンの無料練習問題◯問」と固有名詞、試験日・合格率は表＋FAQ構造化データ、llms.txt
- 「社内で使う」ページ（貸金＝金融、個情保＝総務、衛生管理者＝人事向け）。Teams・ACOM 流入の受け皿

## 7. 共通ルール（他チャットでも守る）
- GA4 イベント名は全サイト共通: `result_view` `affiliate_click` `studio_click` `exam_date_set` `push_subscribed` `daily_complete` `history_sync` `share_click`。`affiliate_click` `studio_click` `sign_up` `pro_subscribed` はキーイベント。
- 共通問題ID: `{site}:{cert}:{qid}`（例 `main:fukushi2:fukushi2-001`）。
- Studio への遷移は `utm_source=shikakumon&utm_medium=referral&utm_content={placement}_{cert}_{band}` を必ず付け、Studio 側は `sign_up` / `pro_subscribed` に `ref_*` を残す。
- アフィリエイトは「広告」明記＋ `rel="nofollow sponsored"`。案件が無い資格には無理に出さない。
- 結果画面の文言は煽らない（得点の事実 → 弱点 → 選択肢）。合格保証めいた表現は禁止。
- 正答率などの統計は n≥30 まで表示しない。回答ログは匿名ID のみ、個人情報は送らない（プライバシーポリシー更新）。
- 「出題予想」は書かない。「正答率が低い＝本番で差がつく論点」と言う。
