# シカクモンの Google 広告（検索広告）の試験運用の設計（2026-10-24）

判断の経緯は `docs/ad-spend-decision-2026-10.md`。SMART合格講座のプログラムでリスティング広告が「可」と確認できた（運営者、2026-10-24）。
そこで判断書 §4 の設計どおり、申込締切前の 10 日間だけ、予算に上限を付けて試す。広告を出すのは本体だけで、Studio には出さない。

前提（判断書 §3）: SMART の成果は月 2〜3 件と小さい。広告 10,000 円を取り戻すには、1 つの窓で試験申込が 7〜13 件、
または講座申込が 2 件増える必要がある。**黒字になる見込みは低く、「元が取れるかを安く確かめる」ための試験**として運用する。

## 2. キャンペーンの設定（2 つとも同じ）

| 項目 | 値 |
|---|---|
| キャンペーンの目標 | 目標を指定せずに作成（ウェブサイトのトラフィック） |
| 種類 | 検索のみ。「ディスプレイ ネットワーク」「検索パートナー」はオフ。P-MAX・動画は使わない |
| 地域・言語 | 日本（「所在地: 対象地域に所在地がある人」）、日本語 |
| 開始日・終了日 | 表 1 の窓の初日・最終日（終了日を必ず入れる） |
| 予算 | 1 日 1,000 円。1 つの窓で 10,000 円まで、2 つで 20,000 円を超えない |
| 入札 | 個別クリック単価制（手動）。上限クリック単価は 1 キーワード 40 円から。自動入札・拡張 CPC は使わない |
| 自動適用のおすすめ | すべてオフ（キーワードや予算を勝手に変えさせない） |
| アセット | サイトリンク（資格トップ・模擬試験・試験日程のコラム）。電話番号・住所は付けない |
| 最終ページ URL のサフィックス | `utm_source=google&utm_medium=cpc&utm_campaign={キャンペーン名}` |

上限クリック単価 40 円は仮の値。`docs/cowork-a8-ad-spend.md` の枠2 で 10/29 の窓の実数が出たら、判断書 §3 の式
（締切前 10 日間の SMART の確定報酬 ÷ その資格のページを見たユーザー数）で出した額に置き換える。

## 3. 広告グループとキーワード

資格ごとに 1 つの広告グループを作り、着地はその資格のトップ（例: `https://shikakumon.com/pii/`）にする。
キーワードはフレーズ一致（`"個人情報保護士 過去問"` の形）。

| 資格名の後ろに付ける語 | 例（個人情報保護士） |
|---|---|
| 過去問 | "個人情報保護士 過去問" |
| 問題集 | "個人情報保護士 問題集" |
| 模試 / 模擬試験 | "個人情報保護士 模試" |
| 申込 / 申し込み | "個人情報保護士 申込" |
| 日程 / 締切 | "個人情報保護士 日程" |

- Search Console で、本体がすでに平均 3 位以内に出ているキーワードは入れない（`docs/cowork-a8-ad-spend.md` の枠3 で確かめる）。
- **A8 の禁止の語の確認（同ファイルの A-1 の 2）で試験名が禁止に入っていた資格は、広告グループごと外す。**

除外キーワード（2 つのキャンペーンに共通。部分一致）:
SMART / 全日本情報学習振興協会 / 協会 / 公式 / 求人 / 転職 / 年収 / 合格発表 / 解答速報 / ログイン / マイページ / 講座（講座名で探す人は広告主へ直接行くため。指名キーワードにも近い）

## 4. 広告文（レスポンシブ検索広告）

見出しは全角 15 文字以内、説明文は全角 45 文字以内。「公式」・協会名・講座名・合格を約束する表現は使わない。
数字は、サイトとコードで確かめられるものだけを書く。下は個人情報保護士の例で、ほかの資格は資格名・回次・締切を入れ替える。

見出し（候補）:
- 個人情報保護士の練習問題
- 無料で解ける模擬試験
- 分野別ドリルと解説つき
- 登録なしですぐ解ける
- 試験日程と申込締切の案内
- 第86回の申込締切は1月28日

説明文（候補）:
- 個人情報保護士の分野別ドリルと模擬試験を無料で公開。解説つきで、登録なしですぐに解けます。
- 第86回の申込締切は1月28日。締切までの日数と試験日程を資格のページで確認できます。

回次と締切は `src/lib/exam-dates.ts`（個人情報保護士 第86回 3/14・締切 1/28 など）。出す前に協会のページと照らす。

## 5. 計測

- サイトに Google 広告のタグは入れない（プライバシーポリシー・AdSense 関連に触れないため）。Google 広告と GA4（プロパティ 537254382）をリンクし、GA4 側で見る。
- 見る数字: 広告の費用・クリック・平均クリック単価（Google 広告）、セッションの参照元 google / cpc の `affiliate_click`（placement が `*_apply` のもの）（GA4）、窓の SMART の発生（A8）。
- GA4 の `affiliate_click` を Google 広告のコンバージョンとして取り込むのは任意（手動入札なので、入札には使わない）。

## 6. 止める条件と判定（判断書 §4 と同じ）

- 3 日目: 実際の平均クリック単価が、上限クリック単価の 1.5 倍を超えるキーワード、表示が出ないキーワードを止める。
- 締切の 7 日後に判定する: 広告経由の申込クリック × その窓の「A8 の成果件数 ÷ 申込クリック数」× 報酬額 を、広告費と比べる。
- 講座の購入はクリックから 18〜47 日後にも出るので、締切の 45 日後にもう一度見る。
- `smart-2701a` で、見積もった売上が広告費の半分に届かなければ、`smart-2701b` はやめるか、個人情報保護士だけにする。

## 7. 進め方

1. 運営者: A8 の A-1 の結果のうち、禁止の語（試験名が入っているか）と「条件付き」の条件を開発側に伝える。
2. 運営者: Google 広告のアカウントを作り、支払い情報を入れる（支払い情報は Cowork・開発側では扱わない）。GA4 とリンクする。
3. Cowork（`docs/cowork-google-ads-setup.md`）: 上の設定どおりに 2 つのキャンペーンを **一時停止の状態で** 作る。
4. 運営者: 内容を確かめてから有効にする（開始日まで配信はされない）。
5. 各窓の終了後に、§6 の判定をこのファイルの末尾に書く。
