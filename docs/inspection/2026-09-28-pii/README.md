# 個人情報保護士 公開済み問題の点検し直し(2026-09-28)

## なぜやったか

模試リマインドのメールへの受験者の返信(「模試よりも本試験の方が文章量が多く、難易度も高く感じた」)を受けて、
模試第1回の課題Ⅰを作り直した(CHANGELOG 2026-09-28)。その作業で読んだ範囲の既存問題だけで、改正の時期の取り違え・
条番号・古い法定刑などの誤りが十数件見つかった。運営者ページ(/about/)で約束している点検
(1問ずつ条文・公式資料と照合し、誤り・答えが2つある問題・改正前の法令のままの問題は直す。解説に根拠条文を添える)に沿って、
公開中の問題を全部点検し直した。

## 対象

- 練習問題 337問(`src/content/pii/`)
- 有料の第2回 100問(`src/lib/pii-moshi2.ts`)
- 第1回の模試専用問題 pii-m1-004(令和8年改正の1問。書いた人とは別の立場での検証)。第1回の模試専用の残り49問は、作成時に同じ観点で独立に検証済み

## 方法

- 点検の仕様(プロンプト)は [prompt.md](./prompt.md)。12 の担当に分け、1問ずつ 4 つの肢の正誤を独立に判定し、
  正解がただ 1 つか、問題文・選択肢・解説(背景知識・学習アドバイス・まとめ・title・description を含む)に
  誤り・改正前の内容・言い過ぎがないかを見た。記録は担当ごとに `record-*.md`(1問1行、根拠と直す前→後)。
- 練習問題は担当がファイルを直接直した。第2回は修正案(JSON)を運営側で反映した(正解の位置と分野名は変えない約束)。
- 選択肢か問題文を変えた問(練習問題 33問・第2回 8問)は、運営側ですべて読み直した。解説だけの修正は担当ごとに抜き取りで確認した。
- 機械検査: `validate-questions.mjs`(形式・問題文の重複)、`audit-questions.mjs`(正解の位置・長さの偏り)、
  `audit-moshi2.mjs`(第2回・第1回の模試専用問題の監査と、無料の問題との重複)、`check-legal-terms.mjs`、本番ビルド。すべて通過。

## 限界

- 個人情報保護委員会・e-Gov・JIPDEC などのサイトは作業環境の通信制限で開けず、条文・ガイドラインは知識と Web 検索の結果の要約で照合した。
  検索はセッションの上限(200回)に途中で達し、後半の担当は一部を知識だけで判定した。各記録の冒頭に、検索で確かめた点が書いてある。
  公式資料を開ける環境で、記録に「※」「確認できなかった」とある点を照合したい。
- 本試験らしさ(問題の形)は、この点検の対象外。練習問題は正解の肢が単独で最長の問が 107問(31%)あり、読まずに長い肢を選ぶと当たりやすい
  (ビルド時の監査の基準「20字以上長い」には当たらない)。形の改善は別の作業として行う。
