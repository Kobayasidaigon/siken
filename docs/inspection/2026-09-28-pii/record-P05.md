# 点検記録 P05(pii-137〜pii-170、34問)

基準日 2026年9月(現行法で判定)。e-Gov・個人情報保護委員会・厚労省などのサイトは通信制限で開けなかった(laws.e-gov.go.jp / www.ppc.go.jp / www.mhlw.go.jp / hourei.net などは 403)。
条文・規則・ガイドライン・Q&A は知識と Web 検索の結果で照合した。検索で裏を取ったのは次の4点(途中でセッションの検索上限 200 回に達し、それ以降は検索できなかった):
(1) 施行規則19条2項=一括作成、19条3項=契約書等での代替、20条=記録事項、21条=保存期間
(2) 補完的ルールは委員会が定めた法的拘束力のある規律。「告示」なのは国の指定(平成31年告示第1号)の方
(3) Q&A 14-15: 自ら保有する個人情報から仮名加工情報を作っても「取得」に当たらず、作成時の利用目的の公表は不要。利用目的を変えたときは公表が必要
(4) 匿名加工情報編ガイドライン: 識別・復元できないかは一般人及び一般的な事業者の能力・手法等で判断し、技術的に全ての可能性を排除することまでは求めない
施行規則17条3項・4項、18条1項、31条、34条の条項番号は検索で確かめられず、記憶による。このため新しく書く解説では項・号まで書かず、既存の記載と矛盾しない範囲にとどめた。

## 令和8年改正(2026年7月17日公布・未施行)について
本範囲で、施行されると正誤が変わると確認できた問はない。ただし、改正法の条文を確認できなかった(通信制限と検索上限のため)。
リポジトリの記載によると改正の柱は、課徴金、16歳未満の子どもの規律、顔特徴データ等、統計作成等での同意規制の緩和、委託先・漏えい等報告・第三者提供の例外・オプトアウトの見直し、罰則など。施行時には次を確認すること(要見直し候補):
- 第三者提供の例外の追加・見直しで、29条1項・30条1項ただし書の適用除外の説明が変わらないか: pii-141・142・147・148
- 統計作成等の例外が仮名加工情報の第三者提供の禁止(41条6項・42条1項)に及ばないか: pii-153・156・160
- 漏えい等報告の見直しで、仮名加工情報の適用除外(41条9項)の記述が変わらないか: pii-155・157
- 条の新設・移動で、28〜30条・41〜46条の条番号がずれないか(範囲の全問)
