## 確信度「中」の問題

作問者が「事実は確かだが、根拠資料の該当箇所を原文で確かめていない」などの理由で「中」を付けた問題。
正解が1つに決まることは解き直しで確認済み。原文照合のときは、下の「要注意」から見るのが効率がよい。

### 要注意（資料によって表記・定義が揺れる、判断が入る）
| 問題 | 気になる点 |
|---|---|
| isf-010 | 現行の JIS Q 27001 本文には PDCA の語が無い。設問で「PDCAサイクルで運用する場合」と前提を置いた |
| isf-018 | 情報資産の分類は旧版 JIS Q 27002:2006 の例示が根拠 |
| isf-043 | JIS Q 27002 の情報転送の管理策に FAX の誤送信への注意がある、という記憶に依存 |
| isf-054 | 複合機の認証印刷を直接扱う公的資料を特定できていない（クリアデスクの考え方からの類推） |
| isf-055 | 「トラッシング」と「スキャベンジング」の呼び方。協会テキストの表記は未確認 |
| isf-065・066 | JIS Q 27002 の管理策の名称が版（2013/2022）で違う。解説は版を断定していない |
| isf-129 | ASCII と ISO/IEC 646 の関係の書き方 |
| dxp-002 | デジタイゼーション→デジタライゼーション→DX の3段階の出典を「DXレポート2」（2020年）とした（解き直しでも指摘） |
| dxp-004 | DXレポート（2018年）が「技術的負債」の語を使っているか |
| dxp-026 | OMO の定義を公的資料で確認できていない |
| dxp-057 | SVOD／AVOD／TVOD は業界用語で、公的資料名を特定できていない |
| dxp-074 | 文化庁「AIと著作権に関する考え方について」の依拠性の扱い（学習に使われていた場合） |
| dxp-088 | ビッグデータの5Vの内訳は資料で違う。解説にその旨を書いた |
| dxp-119・120 | IoTゲートウェイ・テレマティクスは出題範囲の目安に直接の記載が無い（範囲外なら差し替え） |
| dxp-132・136 | マルチクラウド・ベンダーロックインは公的な定義が無い一般用語 |
