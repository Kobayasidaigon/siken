# マイナンバー実務検定1級（/mynumber1/）仕様シート

作成: 2026-11-14

## 公式の仕様（全日本情報学習振興協会 https://www.joho-gakushu.or.jp/nns/ 、2026-11-14 確認）

- 80問、10:00〜12:15（135分）、70%以上で合格（難易度により調整あり）
- 受験料 11,000円（学割8,800円・税込）。令和9年3月開催分から14,300円
- 受験方式: 公開会場（マークシート）・CBT（会場費1,500円）・オンラインIBT（カメラ送料3,000円）
- 受験資格なし
- 出題範囲:「2級の内容に加え、行政および金融機関の実務を含む、マイナンバーとマイナンバーカードの利活用と制限など」。出題項目の表（naiyou.php）では2級と同じ項目に「行政機関等編ガイドライン」「金融業務ガイドライン」が加わり、協会は各5〜10問程度と案内

## 当サイトの構成

- 1級だけの範囲の練習問題 53問: 行政機関等編ガイドライン 001〜026、金融業務ガイドライン 027〜053
- 2級と共通の範囲は /mynumber2/ の150問を案内（同じ問題を2か所に置かない）
- 模擬試験 第1回: 80問・135分・56問以上で合格。行政機関等編8問・金融業務8問・2級の問題64問（2級の模擬試験 第1回で使っていないもの）。正解位置 各20問、難易度 A15/B42/C23
- 問題の元データと生成スクリプト: /mnt/project-files/grade-expansion/mynumber1-src/（gen.py、data_g.py、data_k.py）
