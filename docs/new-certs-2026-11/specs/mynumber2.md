## 4. 未確認・注意

1. 事業者編ガイドラインの別添1（安全管理措置の詳細）・別添2（漏えい等報告の対象事態と期限）は本文を読めていない。そのため、安全管理措置の詳しい項目、中小規模事業者の「5,000人」の基準、漏えい等報告の人数や速報・確報の期限は**出題していない**。
2. 中小規模事業者の定義は委員会の中小向け資料（版不明）で確認した。本文の別添1 とは照合していない。
3. 番号法は改正が多い。第16条の2（機構によるカードの発行）、第18条の2（カード代替電磁的記録）などは 2026-11-14 時点の e-Gov の現行条文で確認した。本試験の法令の基準日は協会が公表していないため、改正の新しい規定は試験に出ない可能性がある。特定在留カード（第18条の5）は施行時期を確かめていないので出題しなかった。
4. 第33条（指導・助言）は取得に失敗したので出題していない。
5. 独立したセッションでの正解を伏せた解き直しは、まだしていない（福祉住環境3級ではした）。
