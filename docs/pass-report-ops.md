# 合格報告の運用手順

利用者から届いた受験報告を、サイトに掲載するまでの手順。2026-09-05 開始。

## 大原則

**掲載するのは実在の投稿だけ。** それらしい文章を作って並べるのは景品表示法のステマ規制
（2023年10月施行）に違反し、このサイトの「事実の正確性」という前提も壊す。
届いていない報告を載せない。届いた文章を書き換えない。この2つだけは絶対に守る。

## 流れ

```
利用者が /goukaku-houkoku/ で投稿
  → POST /api/pass-report（保存はしない）
  → Resend で運営宛メール（dawuzhangguchuan131@gmail.com）
  → 運営が内容を読む
  → 掲載可なら src/content/voices/<slug>.md を作る
  → デプロイ → /voice/ と資格トップに出る
```

自動で公開される経路は無い。メールが届いた時点では、まだどこにも出ていない。

## 掲載するときの判断

載せる。

- 実際に受験した人の報告であることが、内容から無理なく読み取れる
- 出題の傾向・難易度・所要時間など、これから受ける人の役に立つ具体が入っている
- 合格でも不合格でもよい（不合格の報告のほうが役に立つことがある）

載せない。

- **本試験の問題文・選択肢・正答を再現している**。多くの試験は出題内容を第三者に伝えないことを
  受験条件にしており（守秘義務）、載せると投稿者本人が不利益を負う。Ping-t も同じ条件を
  非掲載理由の筆頭に挙げている。運営側も、自作問題に混ざらないよう読み流すこと
- 本名・勤務先・学校名など、投稿者や第三者が特定されうる記述がある
- 特定の教材や講座を過度に持ち上げる、宣伝目的が疑われる文面
- 事実と異なる試験情報（受験料・合格基準など）が断定的に書かれている
  → 掲載を見送るか、投稿者に確認する。こちらで書き換えて載せてはいけない
- 誹謗中傷、差別的な表現
- 同一人物と思われる重複投稿
- 内容が著しく乏しいもの（「受かりました」だけなど）

**謝礼は渡さない。** 図書カードや機能開放と引き換えの投稿は、景品表示法のステマ規制でいう
「利益提供秘匿型」の疑いを招く。対価ゼロで集めることが、最も安全で最も強い。

迷ったら、任意で書かれたメールアドレス宛に確認を送る。返信で本人確認が取れたら
frontmatter に `verified: true` を付ける（表示に「運営で本人に確認済み」が出る）。

## ファイルの作り方

`src/content/voices/<資格ID>-<連番>.md`（例 `kashikin-001.md`）。

```markdown
---
exam: "kashikin"
examPeriod: "2026年11月"
result: "pass"
displayName: "くま"
studyPeriod: "3か月"
score: "50問中38点"
publishedAt: "2026-12-01"
verified: false
---

（届いた本文をそのまま貼る。改行やですます調も直さない）
```

| 項目 | 必須 | 注意 |
|---|---|---|
| `exam` | 必須 | `src/lib/study-progress.ts` の `ExamSlug` と一致させる |
| `examPeriod` | 必須 | **年月まで**。日付は書かない（受験者の特定を避けるため） |
| `result` | 必須 | `pass` または `fail` |
| `publishedAt` | 必須 | 掲載日。新しい順に並ぶ |
| `displayName` | 任意 | 未記入なら「匿名」で出る |
| `studyPeriod` / `score` | 任意 | 自己申告のまま。こちらで補完しない |
| `verified` | 任意 | 本人に確認が取れたときだけ `true` |

必須項目が欠けているファイルは読み飛ばされる（`src/lib/voices.ts`）。書きかけを置いても
公開されないので、下書きのまま置いておいて構わない。

## 削除の依頼が来たら

該当の `.md` を消してデプロイするだけでよい。理由は聞かない。

## 表示される場所

| 場所 | 出るもの | 0件のとき |
|---|---|---|
| `/voice/` | 全件（資格ごとにグループ化） | 報告のお願いのみ。`noindex`、sitemap にも載らない |
| 各資格トップ | その資格の最新3件 | 何も出ない |
| 各資格トップ | 報告のお願い（試験日から45日以内） | 窓の外では何も出ない |

sitemap への追加は自動（`scripts/generate-sitemap.js` が `src/content/voices/` の件数を見る）。

## なぜやるか

1. **講座広告が信用される文脈をつくる**。「この問題で実際に受かった人がいる」の後に置く広告と、
   何の裏付けもない広告では、同じリンクでも成約が変わる。
2. **一次情報が貯まる**。東商のIBT/CBT系（ビジ法・福祉住環境・eco・ビジマネ）や個人情報保護士は
   本試験の問題が非公開で、出題形式の実像は受験者からしか得られない。模試の精度を上げる材料になる。
3. **再訪の理由になる**。試験の後に戻ってくる導線ができる。A8 のクッキーは Safari で7日で切れるため、
   再訪して踏み直してもらうこと自体に金銭的な価値がある（`docs/affiliate-growth-audit.md` §5.1）。
