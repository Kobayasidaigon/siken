# 姉妹ドリルのアクセスを本体と同じ水準に上げる監査と実施（2026-10-31）

対象: 姉妹ドリル 4 サイト（衛生 `eisei-shikaku` / 設備 `setsubi-shikaku` / 筋トレ `kintore-shikaku` / 施工管理 `sekokan`）。
比較: 本体シカクモン（`siken`、shikakumon.com）。再実行用のプロンプトは `docs/sister-traffic-prompt.md`。

方法: 本体の「流入を取れている型」を 1 本の調査で抜き出し、姉妹ごとに 8 つの観点（受け皿の量と形・仕組み・
発見の経路・テンプレート・索引の方針・技術設定・需要と競合・季節）で監査した。そのうえで、リポジトリごとに
実装 → 別担当による独立レビュー（事実の反証・捏造とトーン・技術・抜け）→ 指摘の修正、の順で入れた。
制約: 本番サイト・GA4・Search Console と、多くの公式サイト（exam.or.jp・jctc.jp・fcip-shiken.jp・
nsca-japan.or.jp・health-net.or.jp など）にはこのセッションから接続できない。事実は WebSearch を公式ドメインに
絞った検索結果の本文で照合し、照合できない値は書いていない。数字の「未確認」は §5 の Cowork 依頼で埋める。

## 0. 結論

1. **差の正体は「調べ物のコラム」の量と、タイトルの型。** 本体の流入はコラム 55%・資格トップ 39%で、
   コラムは 165 本（8/18 の 93 本から 2 か月で倍近く）。タイトルを本文の数字入りに書き換えたのも同じ時期で、
   検索クリックは月 974（8/18）→ 28 日 2,447（9/25）に伸びた。姉妹は 25〜70 本で、資格 × 型（過去問・合格率・
   試験日・勉強時間・とは・意味ない・比較・直前）の欠けが多く、タイトルが疑問形や「試験の概要」だった。
   技術設定はほぼ同一で（差は衛生・設備の robots が今の IndexNow キーを塞いでいた 1 点だけ）、設定の違いが原因ではない。
2. **姉妹ごとに 1 つだけやるなら**: 衛生はコラムのタイトルを「検索語 + 公式の数字」の型に、設備は季節の
   日程記事（電験三種の下期申込 11/9〜、冷凍3種 11/8）、筋トレは資格別の過去問・合格率・試験日の記事（今まで 0 本）、
   施工管理は 2 級後期・技術士の「正答と合格発表」の記事（11/8・11/15・11/22 の試験直後の検索を受ける）。
   どれも今回入れた（§3）。
3. **時間で解決する部分**: 新しい 20 本と改題した約 60 ページが索引され順位が落ち着くまで 4〜8 週かかる。
   本体の水準に届くには、今回の型で月 10〜20 本のペースを数か月続ける必要がある（本体が 2 か月で 70 本足したのと同じ）。
   数字は Search Console で 2026-12 中旬と 2027-01 中旬に見る（§5）。

## 2. 姉妹ごとの主な所見（優先度順の上位。全文は各リポジトリの記録にある）

### 衛生管理者ドリル
1. コラムのタイトルが検索語 + 本文の数字の型になっていない（例: 合格率の記事が「難易度は？」の疑問形）。日程の記事が 2 本で食い合い。
2. 共通記事 8 本と頻出系 3 本が内部リンクの行き止まり。第二種の 1 問ページ 600 枚から過去問の記事へリンクが無い。
3. サイト内の事実の食い違い（合格率「4 割前後」と「45%前後」、特例第一種の扱い、労働生理の問題数）。
4. 型の外で需要のある受け皿が無い（計算問題、合格後の免許申請）。
5. robots の `/*.txt$` が今の IndexNow キーのファイルを塞いでいた。
6. コラムのデータが 9/03 以降 2 か月増えていない。

### 設備資格ドリル
1. 電験三種に試験日の記事が無い（令和 8 年度下期の申込 11/9〜11/26）。冷凍 3 種の直前・日程も無い（11/8 試験）。
2. 合格率の数字が本文にあるのに、タイトルは「難易度は？」の疑問形（乙4・乙6・二級ボイラー）。
3. 主力の第二種電気工事士の過去問コラムが 758 字で、公式の過去問ページへのリンクも無い。
4. 日付入りのタイトルが古くなっている（給水装置・公害防止）。工事担任者の資格トップの title に「工事担任者」が入らない。
5. ホームと 1 問ページ 2,828 枚からのコラムリンクが季節ものを先に選んでいた。
6. robots が今の IndexNow キーを塞いでいた。llms.txt の数と姉妹の記載が古い。

### 筋トレ資格ドリル
1. 資格別の過去問・合格率・試験日・勉強時間の記事が 0 本。合格率は「数値を挙げない」方針（`PASSRATE_NOTE`）で、
   公式の公表値（NSCAジャパン・健康・体力づくり事業財団・JATI）があるのに本文が数字を出していなかった。
2. 資格トップの title に「過去問対策」が無い（姉妹の中で筋トレだけ）。
3. コラムに公式の出典リンクが 1 本も無い。「完全ガイド」の表記。
4. 受験者数が小さい（NSCA-CPT 年約 1,200 名、健康運動指導士 1 回 180 人前後）。試験系のクエリだけでは本体の水準に届かない（推測）。
   用語解説の受け皿を自前の問題データから広げるのが次の手（工数 L、今回は見送り）。
5. 問題ページの noindex は真似しない（本体と状況が逆で、問題ページ以外の受け皿がまだ少ない）。

### 施工管理ドリル（2026-09-26 の監査 `sekokan/docs/seo-gap-audit.md` の続き）
1. 2 級後期と技術士で、試験直後から合格発表までの検索（正答・合格発表・合格基準）を受けるページが無い。
2. 過去問の受け皿に、公式の公開期間（1 年間）という最大の事実が書かれていない。
3. コラム一覧の分類の固定配列から「分野別の対策」が抜け、3 本が一覧に出ていなかった。
4. 試験別ガイドの合格率が古い、タイトルに数字が無い。10/19 に追加した電気通信・技術士への導線が弱い。
5. 技士補・受験資格・落ちたらなど、資格 × 型の記事が試験別にほとんど無い。
6. Search Console・Bing・IndexNow の手作業が、記録の上では終わっていない。

## 6. やらないほうがよいこと

1. **姉妹の問題ページを本体と同じく noindex にする。** 本体は問題ページの流入が 2.2%で、AdSense 再申請のために外した。
   姉妹は問題ページ以外の受け皿がまだ少なく、問題ページの流入の比率も未確認。Search Console の「ページ別」の数字を見てから決める。
2. **照合していない数字で記事を量産する。** 本体の伸びは「本文の事実の数字をタイトルに出す」型で、数字が間違っていれば
   信頼も順位も落ちる。照合できない値は書かない、の決まりを崩さない。予備校の値しか無いものは「公式で確認」と案内する。
3. **技術設定をこれ以上いじる。** robots の IndexNow キー以外、本体と姉妹の設定に差は無かった。差の無いところを直しても動かない。
