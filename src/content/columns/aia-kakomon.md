AI活用アドバイザー認定試験の過去問を、全問そのまま公開している公式のページは、当サイトが調べた範囲では見つかりませんでした（2026年10月時点）。ただし、協会の公式サイトにはサンプル問題10問と無料の学習資料があり、公式のテキストと問題集も市販されています。この記事では、何をどこで手に入れられるかを整理します。

なお、第14回（2026年10月18日実施）の解答速報は、2026年10月19日の時点で当サイトでは確認できていません。

## 公式のサンプル問題10問を最初に解く

サンプル問題は、**本試験の出題形式を知るのにいちばん確実な資料**です。解くときは、内容より形式に注目してください。

- 2択と4択が混在していること
- 「下線部が正しいものを選ぶ」形式と、「最も不適切なものを選ぶ」形式があること
- 事例の問題では、固有名詞や技術名を入れ替えた誤りの選択肢が使われること
- 人材・導入動向の問題では、日本と米国の傾向の取り違えが問われること

10問の量なので、1回で終わらせず、間違えた問題が属する課題をメモして、その課題の勉強に戻る使い方が向いています。当サイトでは、公式の問題を転載せず、自作の練習問題で演習できるようにしています。

### 購入前に確かめたいこと

公式テキストは、版・発行年月が協会の学習ページに書かれていません。2024年12月付とみられる正誤表が公開されているものの、**2026年6月から加わった第3課題「生成AIの基礎知識」を、どこまでカバーしているかは確認できていません**。購入するときは、書店やネット書店の商品ページで発行年月を確かめ、不安な場合は協会に問い合わせるのが確実です。

また、協会は、公式テキストに載っているのは「AI事業者ガイドライン案」で、案または第1.0版のどちらを学習しても試験に対応できると案内しています。

### そのほかの参考書籍

協会の案内では、参考書籍として「AI白書2020」「AI白書2022」（角川アスキー総合研究所）のほか、AIのビジネス活用を扱った一般書が挙げられています。いずれも試験範囲を網羅する教材ではないので、読み物として補う位置づけで十分です。

協会は「SMART合格講座」という動画講座も用意しています。当サイトが確認した範囲では、講座単体は17,600円、講座と受験のセットは25,300円（いずれも税込、2026年10月時点）です。

ただし、**講座の紹介ページには、2026年10月19日時点で「5課題・90分」という旧仕様の記載が残っていました**。現在の試験は7課題・105分です。講座を申し込むなら、第3課題（生成AI）を含む内容かどうかを、事前に公式ページや協会への問い合わせで確かめてください。独学でも、テキストと無料資料、問題演習で十分に対応できる範囲です。

## 当サイトの練習問題144問の使い方

当サイトの[AI活用アドバイザー練習問題](/aia/)は、144問を7つの分野に分け、解説つきで無料公開しています。すべて当サイト編集部が作ったオリジナル問題で、本試験の過去問の転載ではありません。

| 分野 | 本試験の課題 |
|---|---|
| [AIの基礎知識・用語](/aia/field/basics/) | 第1課題 |
| [AIの技術](/aia/field/tech/) | 第2課題 |
| [生成AIの基礎知識](/aia/field/genai/) | 第3課題 |
| [AIプロジェクトの流れ](/aia/field/project/) | 第4課題 |
| [企業・団体のAI導入事例](/aia/field/cases/) | 第5課題 |
| [人材・AIの導入動向](/aia/field/human/) | 第6課題 |
| [AIの制度・政策動向](/aia/field/policy/) | 第7課題 |

使い方の流れは次のとおりです。

1. 公式のサンプル問題10問で、出題形式を確かめる
2. 本番と同じ100問・105分の[模擬試験](/aia/moshi/)で、課題ごとの弱点を確認する
3. 弱い課題の分野に戻り、[第1問](/aia/q/aia-001/)などから順に解く
4. 間違えた問題は、取り違えた点を一言で書き出し、公式テキストや無料の学習資料で確認する
5. 最後にもう一度、模擬試験で107点相当（70%）を安定して超えるかを確かめる

本試験の問題は、練習問題と同じ文面では出ません。選択肢の言い回しを覚えるのではなく、**なぜその選択肢が正しいのかを、用語の意味や資料の内容で説明できる状態**を目指してください。
