AI活用アドバイザー認定試験の次回は、2027年4月18日（日）の第15回です。申込は2026年11月2日（月）から2027年3月11日（木）までです。この記事では、試験日と申込期間、受験料、申込の流れ、締切の注意点をまとめます（2026年10月31日時点、協会の公式案内にもとづきます）。

## 試験日程

AI活用アドバイザー認定試験は、全日本情報学習振興協会が年2回実施しています。直近の3回は次のとおりです。

| 回 | 試験日 | 申込期間 |
|---|---|---|
| 第13回 | 2026年6月21日（日） | 実施済み |
| 第14回 | 2026年10月18日（日） | 2026年6月9日〜9月10日（実施済み） |
| 第15回 | **2027年4月18日（日）** | **2026年11月2日（月）〜2027年3月11日（木）** |
| 第16回 | 2027年11月（日付は未定） | 未定 |

（出典: 全日本情報学習振興協会「AI活用アドバイザー認定試験」のページと試験日程の一覧、2026年10月31日確認。以前このページで「第15回は3月14日」としていたのは誤りでした）

**第14回は2026年10月18日に実施済みです。** 次に受けられるのは第15回（2027年4月18日）で、申込の受付は11月2日に始まります。それ以降の回の日程は、決まりしだい公式サイトで案内されます。

## 受験料と試験の形式

| 項目 | 内容 |
|---|---|
| 受験料 | 一般14,300円（第15回から。第14回までは11,000円）／学割は公式で確認（税込） |
| 割引 | 資格者部会の会員は受験料20%割引 |
| 問題数 | 100問（2択48問×1点、4択52問×2点、152点満点） |
| 試験時間 | 10:00〜11:45（105分） |
| 合格基準 | 70%（107点）以上。問題の難易度により調整する場合あり |
| 出題範囲 | 7課題（AIの基礎知識／AIの技術／生成AIの基礎知識／AIプロジェクトの流れ／企業・団体のAI導入事例／人材・AIの導入動向／AIの制度・政策動向） |

### 受験料の改定

協会の案内では、**令和9年（2027年）4月開催分から、受験料が14,300円に改定される予定**です。学割の改定後の額は記載がありません。

第15回は2027年4月18日の開催なので、**改定後の14,300円が適用される回**です。どの回にどの料金が適用されるかは申込のときの案内が優先されるので、必ず公式サイトで確認してください。

### 受験方式と追加費用

| 方式 | 内容 | 追加費用 |
|---|---|---|
| 公開会場 | マークシート方式 | 0円 |
| CBT | テストセンターのPCで受験 | 1,500円 |
| オンラインIBT | 自宅などでPCと360度Webカメラを使って受験 | 3,000円（カメラの往復送料） |

改定後の一般の受験料で比べると、公開会場は14,300円、CBTは15,800円、オンラインIBTは17,300円です（いずれも税込）。**第15回でどの方式を選べるか、CBT・IBTの申込期間が公開会場と同じか**は、当サイトでは確認できていません。申込の前に公式サイトで確かめてください。

## 申込の流れ

申込は、全日本情報学習振興協会のAI活用アドバイザー認定試験のページ（https://www.joho-gakushu.or.jp/ai-advisor/ ）にある「申込」のコーナーから行います。

1. 公式ページで、受験する回と受験方式（公開会場・CBT・オンラインIBT）を選ぶ
2. 案内に沿って、氏名・連絡先などを入力する
3. 受験料（と、方式によっては追加費用）を支払う
4. 試験が近づいたら、届く案内で当日の時間や受験方法を確認する

学割の対象条件や、会場の場所、オンラインIBTで必要な機材は、申込のときの最新の案内で確認してください。

## 申込で気をつけること

### 受付開始までは申し込めない

第15回の受付は2026年11月2日からです。締切日（2027年3月11日）をカレンダーに入れておくと、うっかり忘れを防げます。

### 締切は試験日の6週間ほど前

第15回の締切（2027年3月11日）から試験日（4月18日）までは、約5週間あります。**締切の時点では試験まで1か月以上あるので、「まだ勉強が終わっていないから」と申込を後回しにしない**ほうが安心です。先に申し込んでしまい、試験日から逆算して準備するのが、結果的に続けやすい進め方になります。

### 旧仕様の情報に注意する

2026年6月の第13回から、出題範囲が5課題から7課題に変わりました（第3課題として「生成AIの基礎知識」が加わりました）。試験時間も105分です。講座の紹介ページなどに「5課題・90分」という旧仕様の記述が残っていることがあるので、**日程・形式・受験料は、協会の試験案内のページを一次情報として確認**してください。

## 試験日から逆算して準備する

勉強時間の公式な目安は公表されていません。当サイトの目安では、業務でAIやITに触れている方で20〜30時間、ほとんど知識がない方で40〜50時間ほどです（個人差があります）。第15回を目標にするなら、次のように考えられます。

| 時期 | やること |
|---|---|
| 2026年11〜12月 | 申込開始（11月2日）。模擬試験で現在地を確認し、基礎・技術の課題から始める |
| 2027年1月 | 生成AIと導入事例の課題。事例は量が多いので、少しずつ進める |
| 2027年2月 | 人材・導入動向と制度・政策。申込の締切（3月11日）の前に受験を確定する |
| 2027年3月〜4月上旬 | 模擬試験で107点相当（70%）を安定して超えるまで解き直す |

具体的な進め方は[AI活用アドバイザーの勉強法と勉強時間](/column/aia-benkyouhou/)にまとめています。

## 申込を済ませたら

まず、本試験と同じ100問・105分の[模擬試験](/aia/moshi/)で、7つの課題のどこが弱いかを確かめてください。そこから[練習問題144問](/aia/)の該当分野に戻るのが、いちばん無駄の少ない進め方です。

試験の全体像は[AI活用アドバイザー認定試験とは](/column/aia-toha/)、教材やサンプル問題は[過去問・サンプル問題と教材の入手先](/column/aia-kakomon/)で扱っています。

試験日程・受験料は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
