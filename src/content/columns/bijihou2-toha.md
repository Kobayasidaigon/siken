ビジネス実務法務検定試験®は、東京商工会議所が実施する、企業活動にかかわる法律知識の検定です。3級・2級・1級があり、3級と2級はIBT方式かCBT方式を選んで受ける多肢選択式の試験、1級は2022年度からCBT方式による統一試験で実施されています。公式の学習サポートのページでは、2級は「企業の管理職、総務・法務、コンプライアンス等の担当者」におすすめとされています。この記事では、2026年11月10日時点の公式サイトの情報をもとに、3級との違いと、2級で何を学ぶのかを整理します。

## 3級との違い

受験案内では、3級の出題範囲は、3級公式テキスト（2026年度版）の基礎知識と、それを理解したうえでの応用力とされています。2級の出題範囲は、3級の範囲と、2級公式テキスト（2026年度版）の基礎知識、それを理解したうえでの応用力です。2級の範囲には、3級の範囲も含まれます。

当サイトでは、3級と2級の差は範囲の広さだけでなく、問題への取り組み方にもあると考えています。2級の対策では、条文を覚えるだけでなく、示された事例で**どの法律のどの規定が働くかを自分で選び、結論を出す**練習をおすすめします。

範囲も広がります。2級公式テキスト（2026年度版）は序章と第1章〜第16章、3級公式テキスト（2026年度版）は第1章〜第8章からなります。2級には、3級の章の題名には出てこない、次のようなテーマの章があります。

- 第6章 デジタル社会と法律
- 第8章 金融・証券業等に関する法規制
- 第11章 債務者の倒産への対応
- 第12章 法的紛争等の予防と対応
- 第15章 企業活動と地域社会・行政等とのかかわり
- 第16章 国際法務（渉外法務）

債権については、3級の第5章「債権の管理と回収」が、2級では第9章「債権の担保」と第10章「債権の回収」の2章に分かれています。

金融・証券や倒産、国際法務のように、法務部門にいなければ日常の業務で触れる機会が少ないテーマは、実務経験の有無によって取り組みやすさが変わりやすいと当サイトでは考えています。

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施団体 | 東京商工会議所 |
| 受験方式 | IBT方式（自宅や会社などで自分のパソコンを使う）またはCBT方式（全国各地のテストセンター）を選択 |
| 出題形式・試験時間 | 多肢選択式・90分 |
| 合格基準 | 100点満点中70点以上 |
| 受験資格 | 学歴・年齢・性別・国籍による制限なし（3級を受けずに2級から受験できる） |
| 受験料（税込） | IBT方式7,700円、CBT方式7,700円＋CBT利用料2,200円 |
| 出題範囲 | 3級の範囲と、2級公式テキスト（2026年度版）の基礎知識およびそれを理解したうえでの応用力。第59回・第60回は2025年12月1日現在成立している法律に準拠 |
| 合格者の称号 | ビジネス法務エキスパート® |

表の内容は2026年11月10日時点の受験案内によります。2027年度の第61回・第62回の法令の基準日は、2026年11月10日時点の受験案内には載っていません。

**問題数は受験案内に載っていません。** 2026年11月10日時点の受験案内には、出題形式（多肢選択式）、試験時間（90分）、合格基準（100点満点中70点以上）は載っていますが、2級の問題数は書かれていません。

当サイトの[模擬試験 第1回](/bijihou2/moshi/)は、この90分・100点満点・70点合格という条件に合わせ、50問×2点＝100点満点として作っています。これは当サイト独自の構成で、本試験の問題数を示すものではありません。

受験日時は、回ごとに設けられる試験期間の中から、申込のときに選びます。申込期間は試験期間より前にあり、申込が締め切られてから試験期間が始まります。2026年11月10日時点では、2・3級の2026年度の回（第59回・第60回）はどちらも実施済みで、次に申し込める第61回（2027年度）は、申込期間が2027年5月14日〜5月25日、試験期間が2027年6月17日〜7月5日と公表されています。第62回を含む日程と申込の流れは[試験日程の記事](/column/bijihou-nittei/)にまとめています。

## 合格率

東京商工会議所の受験者データ（全国分）では、2級の合格率は、第57回（2025年度第1シーズン）が35.4%、第58回（2025年度第2シーズン）が43.3%、第59回（2026年度第1シーズン）が35.6%で、2025年度合計は39.8%でした。第60回の結果は、2026年11月10日時点の受験者データにはまだ載っていません。

同じ回の3級の合格率は、第57回が57.6%、第58回が38.3%、第59回が56.9%（2025年度合計は47.6%）です。第57回と第59回は2級のほうが20ポイント以上低い一方、第58回は2級のほうが5.0ポイント高くなりました。当サイトでは、合格率の数字だけでなく範囲の広さもあわせて、難しさを考えることをおすすめします。回ごとの数字の見方は[2級の難易度の記事](/column/bijihou2-nanido/)で紹介しています。

## 当サイトの10分野

当サイトでは、2級の練習問題を、公式テキストの章立てに沿って次の10分野に分けています。かっこ内は、対応する公式テキストの章と、当サイトで扱っている論点の例です。

- [企業取引・契約の法務](/bijihou2/field/torihiki/)（第1章。代理、契約の成立と解除、同時履行の抗弁権）
- [企業財産の管理と法務](/bijihou2/field/zaisan/)（第2章。不動産登記、共有、特許権などの取得手続）
- [企業間取引の法規制](/bijihou2/field/kigyoukan/)（第3章。独占禁止法の不当な取引制限、優越的地位の濫用）
- [消費者取引と広告・表示の法規制](/bijihou2/field/shouhisha/)（第4章・第7章。消費者契約法、特定商取引法、景品表示法）
- [情報の管理・活用とデジタル社会](/bijihou2/field/jouhou/)（第5章・第6章。個人情報保護法、匿名加工情報）
- [金融・証券業等に関する法規制](/bijihou2/field/kinyuu/)（第8章。開示制度、インサイダー取引）
- [債権の担保と回収](/bijihou2/field/saiken/)（第9章・第10章。保証、抵当権、物上代位）
- [倒産処理と紛争の予防・解決](/bijihou2/field/tousan/)（第11章・第12章。破産債権と財団債権、相殺の制限）
- [株式会社の組織と運営](/bijihou2/field/kaisya/)（第13章。譲渡制限株式、組織再編、事業譲渡）
- [企業と従業員・地域社会・国際法務](/bijihou2/field/juugyouin/)（第14章〜第16章。36協定、解雇権濫用法理）

当サイトでは、**民法と会社法**を学習の軸にすることをおすすめします。この2つが分かっていると、ほかの分野の法律を「民法の原則に何が上乗せされているか」という見方で読めるからです。たとえば消費者契約法は、事業者が勧誘の際に法律で定められた行為をし、それによって消費者が誤認したり困惑したりして契約の申込みや承諾をした場合などに、消費者が取り消せることを定めています（4条）。民法が定める詐欺・強迫による取消し（96条1項）と並べて読むと、どこが広がっているのかがつかみやすくなります。逆に、民法があいまいなまま個別の法律を暗記すると、事例の問題で判断に迷いやすくなると当サイトでは考えています。

## どんな人に向いているか

東京商工会議所の学習サポートのページでは、2級は「企業の管理職、総務・法務、コンプライアンス等の担当者」におすすめとされています。また、ビジネス実務法務検定試験®の紹介ページでは、法務部門に限らず、営業・販売・総務・人事などのあらゆる職種で必要とされる法律知識が身につく検定と説明されています。

当サイトでは、契約書を扱う営業・購買などの担当者や、3級の学習を終えて次の段階に進みたい方にも、2級の範囲を学ぶことが役立つと考えています。

## まず何から始めるか

2級は3級を受けずに受験できますが、出題範囲には3級の範囲も含まれます。民法の基礎に不安がある方には、当サイトでは、先に3級の範囲を一通り確かめることをおすすめします。[ビジネス実務法務検定3級の練習問題](/bijihou/)も当サイトで公開しています。

2級については、当サイトで[ビジネス実務法務検定2級の練習問題](/bijihou2/)を解説つきで無料公開しています。当サイトでは、事例へのあてはめに慣れるために、分野別に解いたあと、分野をまたいで通しで解く練習をおすすめします。通しで解く形式には、50問を90分で解く[模擬試験 第1回](/bijihou2/moshi/)と、ランダムに20問を出題して分野別の正答率を表示する[本番形式テスト](/bijihou2/mock/)（時間制限なし）があります。どちらの問題数も当サイトの構成によるもので、本試験の問題数を示すものではありません。登録は不要です。

この記事の内容は2026年11月10日時点のものです。試験期間・申込期間・受験料は、申込の前に東京商工会議所の受験案内でご確認ください。
