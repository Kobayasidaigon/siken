会社法法務士認定試験は、60問・150分で、正答率70%が合格の基準です。この記事では、勉強時間の目安と、会社法の各編をどの順番で、どう押さえるかをまとめます。

試験の全体像は[会社法法務士認定試験とは](/column/cac-toha/)で整理しています。

## 勉強時間の目安

公式の目安は公表されていないので、ここに書くのは当サイトの目安です。

| これまでの経験 | 勉強時間の目安 | 期間の例 |
|---|---|---|
| ビジネス実務法務検定2級・司法書士などで会社法を学んだ | 30〜40時間 | 1日1時間で1か月〜1か月半 |
| 総務・法務で株主総会や取締役会の運営に関わっている | 50〜60時間 | 1日1時間で2か月 |
| 会社法を学んだことがない | 70〜90時間 | 1日1時間で2か月半〜3か月 |

差がつくのは、**機関（株主総会・取締役・監査役・委員会）と組織再編**です。

## 教材の選び方

協会の稟議書の例文には「市販の会社法の書籍が利用できる」とあり、公式サイトには「参考書籍」のページもあります。選ぶときは、**令和元年改正（2021年3月施行）に対応していること**を確かめてください。株主総会資料の電子提供制度、社外取締役の設置義務、会社補償・D&O保険、株式交付が載っていれば対応済みです。

問題演習には、当サイトの[練習問題160問](/cac/)と、本番と同じ60問・150分の[模擬試験](/cac/moshi/)が使えます。どちらも無料で、登録は要りません。

## 分野ごとの進め方

### 1. まず「会社の形」の区別を覚える

最初に、次の区別を頭に入れます。会社法の問題の多くは、この区別で答えが変わります。

| 区別 | 意味 |
|---|---|
| 公開会社・非公開会社 | 株式の譲渡制限が全部の株式についているかどうか |
| 大会社 | 資本金5億円以上、または負債200億円以上 |
| 取締役会設置会社 | 取締役会を置く会社（公開会社は必ず置く） |
| 機関設計 | 監査役（会）設置会社・監査等委員会設置会社・指名委員会等設置会社 |

### 2. 機関：株主総会と取締役

次に機関に進みます。出題がもっとも多いと考えられる範囲です。

**株主総会**は、招集の手続（公開会社は2週間前までに通知）、決議の要件、書面・電子投票、決議の取消し・無効・不存在の訴えを整理します。

| 決議 | 要件（原則） | 主な例 |
|---|---|---|
| 普通決議 | 議決権の過半数を持つ株主が出席し、出席株主の議決権の過半数 | 取締役の選任、計算書類の承認 |
| 特別決議 | 議決権の過半数を持つ株主が出席し、出席株主の議決権の3分の2以上 | 定款の変更、合併、事業の全部の譲渡 |
| 特殊決議 | 株主の半数以上かつ議決権の3分の2以上など | 株式に譲渡制限をつける定款の変更 |

**取締役・取締役会**は、競業取引・利益相反取引の承認、取締役会の決議事項、役員の責任と責任の免除を押さえます。

### 3. 設立・株式・新株予約権

設立は、発起設立と募集設立の違い、変態設立事項、設立時の責任が中心です。株式は、株式の種類、譲渡制限、自己株式の取得、募集株式の発行、株式の併合・分割を区別します。

### 4. 計算・組織再編

計算では、剰余金の配当と分配可能額の規制、違法配当の責任が問われます。組織再編（合併・会社分割・株式交換・株式移転・株式交付）は、**反対株主の株式買取請求、債権者異議手続、簡易・略式の手続**の要件を、再編の種類ごとに表にまとめると整理しやすくなります。

### 5. 持分会社・社債・解散と清算

最後に、実務で触れる機会の少ない範囲を固めます。持分会社は、合名・合資・合同会社の社員の責任（無限責任・有限責任）の違いが基本です。

## 8週間のスケジュール例

1日1時間〜1時間半、会社法を学んだことがない人を想定した例です。

| 週 | やること |
|---|---|
| 1週目 | 模擬試験で現在地を確認。会社の形の区別を覚え、総則・設立の20問 |
| 2週目 | 株式・新株予約権の20問 |
| 3週目 | 機関①（株主総会）の20問。決議の要件を表にまとめる |
| 4週目 | 機関②（取締役・監査役・委員会）の20問 |
| 5週目 | 計算・定款変更・事業譲渡の20問 |
| 6週目 | 組織再編の20問。再編の種類ごとの手続を表にする |
| 7週目 | 持分会社・社債、解散・清算・外国会社・雑則の40問 |
| 8週目 | 間違えた問題を解き直し、模擬試験で42問（70%）以上を確認 |

## まとめ

- 勉強時間の目安は、経験に応じて30〜90時間。差がつくのは機関と組織再編
- 公開会社か、取締役会を置くか、大会社かで答えが変わる。最初にこの区別を覚える
- 数字（期限・決議要件・持株要件）は表にまとめる
- 持分会社・社債・清算など、実務で触れない範囲も落とさない

試験日と申込締切は[会社法法務士の試験日程](/column/cac-nittei/)で確認できます。練習問題は[こちら](/cac/)から、[第1問](/cac/q/cac-001/)から順に解けます。
