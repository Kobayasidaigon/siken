会社法法務士認定試験は、会社法の知識を問う認定試験です。全日本情報学習振興協会が実施しています。この記事では、何を問う試験なのか、出題範囲と合格基準、受けるメリットを整理します（2026年11月1日時点、協会の公式案内にもとづきます）。

## どんな試験か

協会は「会社法は企業法務を行う上では必須の法律」「会社法法務士は人事・総務等に必須の会社法のプロを認定する」と説明しています。

問われるのは、たとえば次のような判断です。

- 株主総会を招集するには、いつまでに、誰に通知を出す必要があるか
- 取締役が会社と取引をするとき、どんな承認が要るか
- 剰余金の配当は、いくらまでできるか
- 吸収合併に反対する株主は、会社に何を請求できるか

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 60問・150分（開催時間は10:00〜12:45） |
| 合格基準 | 70%以上（問題の難易度により調整し、70%未満でも合格とする場合がある） |
| 受験料 | 一般16,500円／学割13,200円（税込） |
| 追加費用 | CBTは会場費1,500円、オンラインIBTはカメラの往復送料3,000円 |
| 受験方式 | 公開会場（マークシート）・CBT・オンラインIBT |
| 試験日 | 年2回程度 |

（出典: 全日本情報学習振興協会「会社法法務士認定試験」のページ、2026年10月31日確認）

次の回の試験日は、協会の案内で表記が2つに分かれています（2027年2月21日と6月27日）。詳しくは[会社法法務士の試験日程](/column/cac-nittei/)にまとめています。

## 出題範囲

出題範囲は、会社法の条文の構成に沿って示されています。

| 編 | 主な内容 |
|---|---|
| 第1編 総則 | 会社の種類、商号、会社の使用人・代理商 |
| 第2編 株式会社 | 設立、株式、新株予約権、機関（株主総会・取締役・監査役・委員会など）、計算、定款の変更、事業の譲渡、解散、清算 |
| 第3編 持分会社 | 合名会社・合資会社・合同会社 |
| 第4編 社債 | 社債の発行、社債管理者、社債権者集会 |
| 第5編 組織変更・合併など | 組織変更、合併、会社分割、株式交換、株式移転、株式交付 |
| 第6編 外国会社 | 外国会社の登記・代表者 |
| 第7編 雑則 | 会社の解散命令、訴訟、登記、公告 |

第8編の罰則からは出題されません。編ごとの問題数は公表されていません。当サイトでは、第2編を5つ、ほかの編を組み合わせて3つ、合わせて8分野・各20問の練習問題として並べています。

## 改正点を意識する

2021年3月1日に施行された令和元年の改正で、次のような制度が加わりました。

- 株主総会資料の電子提供制度（2022年9月1日施行）
- 上場会社などでの社外取締役の設置の義務づけ
- 取締役の報酬の決定方針、会社補償・役員等賠償責任保険契約（D&O保険）
- 株式交付の制度

古い教材だと、これらの論点が抜けています。教材を選ぶときは、令和元年改正に対応しているかを確かめてください。

## 受けるメリット

合格すると、合格証書と写真入りの認定カードが交付され、名刺などに認定ロゴを使えます。

- 総務・法務・経営企画の担当者が、株主総会や取締役会の運営に必要な知識を体系的に確かめられる
- 起業を考えている人や経営者が、株式会社・合同会社の仕組みを理解できる
- 司法書士・行政書士など、会社法が出る国家試験の前に、条文の全体を一通り確かめられる

関連する試験として、民法の全体を扱う[民法法務士](/ccc/)、企業の危機管理を扱う[企業危機・コンプライアンス管理士](/ccm/)、取引法務の全体を扱う[ビジネス実務法務検定2級](/bijihou2/)もあります。

## まず何から始めるか

当サイトでは[会社法法務士の練習問題](/cac/)を160問、条文の根拠つきの解説で無料公開しています。最初に、本試験と同じ60問・150分の[模擬試験](/cac/moshi/)で、どの分野が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[本番形式テスト](/cac/mock/)が使えます。登録は不要です。

勉強の進め方は[会社法法務士の勉強法と勉強時間](/column/cac-benkyouhou/)、難易度は[会社法法務士の合格率と難易度](/column/cac-goukakuritsu/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
