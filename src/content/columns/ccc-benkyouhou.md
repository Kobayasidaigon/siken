民法法務士認定試験は、70問・150分で、正答率70%が合格の基準です。この記事では、勉強時間の目安と、民法の6分野をどの順番で、どう押さえるかをまとめます。

試験の全体像は[民法法務士認定試験とは](/column/ccc-toha/)で整理しています。

## 勉強時間の目安

公式の目安は公表されていないので、ここに書くのは当サイトの目安です。

| これまでの経験 | 勉強時間の目安 | 期間の例 |
|---|---|---|
| 宅建・ビジネス実務法務検定2級・行政書士などで民法を学んだ | 30〜40時間 | 1日1時間で1か月〜1か月半 |
| 仕事で契約書に触れるが、民法を通して学んだことはない | 50〜60時間 | 1日1時間で2か月 |
| 法律を学んだことがない | 80〜100時間 | 1日1時間で3か月 |

差がつくのは、**債権総論と債権各論**です。条文の数が多く、改正の影響も大きい分野です。

## 教材の選び方

協会の公式サイトには「参考書籍」のページがあり、市販の民法の本を使って学べます。選ぶときは次の2点を確かめてください。

- **2020年4月施行の債権法改正に対応していること**（発行年が2020年以降のもの）
- **親族・相続まで扱っていること**（債権法だけの本では範囲が足りない）

問題演習には、当サイトの[練習問題160問](/ccc/)と、本番と同じ70問・150分の[模擬試験](/ccc/moshi/)が使えます。どちらも無料で、登録は要りません。

## 分野ごとの進め方

### 1. 民法総則：すべての土台

最初に取り組むのは民法総則です。権利能力・意思能力・行為能力、意思表示（心裡留保・虚偽表示・錯誤・詐欺・強迫）、代理、無効と取消し、時効は、ほかの分野の問題を読む前提になります。

特に**意思表示の5つの型**は、「誰に対して無効・取消しを主張できるか（第三者の保護）」まで表にして覚えると、事例問題で迷いません。

| 型 | 効果 | 善意の第三者に対抗できるか |
|---|---|---|
| 心裡留保 | 原則有効（相手方が知り、または知ることができたときは無効） | 対抗できない |
| 通謀虚偽表示 | 無効 | 対抗できない |
| 錯誤 | 取り消せる | 善意・無過失の第三者に対抗できない |
| 詐欺 | 取り消せる | 善意・無過失の第三者に対抗できない |
| 強迫 | 取り消せる | 対抗できる |

### 2. 債権総論・債権各論：改正点を中心に

次に債権に進みます。債務不履行と損害賠償、保証、債権譲渡、弁済と相殺、契約の解除、売買・賃貸借・請負などの典型契約、不法行為が中心です。

改正で変わった点は、正誤問題の材料になりやすい論点です。

- **消滅時効**: 権利を行使できることを知った時から5年、行使できる時から10年（人の生命・身体の侵害による損害賠償は長くなる）
- **法定利率**: 年3%で、3年ごとに見直す変動制
- **保証**: 事業のための貸金等債務の個人保証は、原則として公正証書による意思確認が必要
- **売買**: 「瑕疵担保責任」から「契約不適合責任」へ。買主は追完・代金減額・損害賠償・解除を請求できる

### 3. 物権：登記と対抗要件

物権では、**不動産の物権変動は登記がなければ第三者に対抗できない**（177条）という原則と、その例外を整理します。二重譲渡、取得時効と登記、相続と登記は、登場人物を図に書いて解く練習をしてください。2023年4月施行の改正で変わった相隣関係・共有のルールも確認します。

### 4. 親族・相続：数字と順番を正確に

親族は婚姻が中心です。相続は、相続人の順位と法定相続分、承認と放棄（熟慮期間3か月）、遺言の方式、遺留分、配偶者居住権が頻出です。数字で正誤が決まる問題が多いので、表にまとめて覚えるのが近道です。

## 8週間のスケジュール例

1日1時間〜1時間半、民法を学んだことがない人を想定した例です。

| 週 | やること |
|---|---|
| 1週目 | 模擬試験で現在地を確認。民法総則①（人・法律行為・意思表示）の20問 |
| 2週目 | 民法総則②（代理・無効と取消し・時効）の20問 |
| 3週目 | 物権の20問。登記と対抗要件を図で整理する |
| 4週目 | 債権総論①（債権の効力・債務不履行・保証）の20問 |
| 5週目 | 債権総論②（債権譲渡・弁済・相殺）の20問 |
| 6週目 | 債権各論①（契約）・②（事務管理・不当利得・不法行為）の40問 |
| 7週目 | 親族・相続の20問。数字を表にまとめる |
| 8週目 | 間違えた問題を解き直し、模擬試験で49問（70%）以上を確認 |

## まとめ

- 勉強時間の目安は、経験に応じて30〜100時間。差がつくのは債権
- 総則（とくに意思表示と代理）を最初に固める
- 2020年4月の債権法改正の論点を重点的に押さえる
- 物権は登記と対抗要件、相続は数字と順番を表で覚える

試験日と申込締切は[民法法務士の試験日程](/column/ccc-nittei/)で確認できます。練習問題は[こちら](/ccc/)から、[第1問](/ccc/q/ccc-001/)から順に解けます。
