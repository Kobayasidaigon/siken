民法法務士認定試験は、民法の全体を問う認定試験です。全日本情報学習振興協会が実施しています。この記事では、何を問う試験なのか、出題範囲と合格基準、受けるメリットを整理します（2026年11月1日時点、協会の公式案内にもとづきます）。

## どんな試験か

民法は、契約・所有権・損害賠償・家族・相続など、社会生活と取引の基本ルールを定めた法律です。協会は、この試験で「民法の主要論点と改正点を学び、新しい時代のルールを知ることができる」としています。

問われるのは、たとえば次のような判断です。

- 未成年者が親の同意なしに結んだ契約は、あとから取り消せるか
- 代理人が権限の範囲を超えて結んだ契約に、本人は責任を負うか
- 売った物に欠陥があったとき、買主は何を請求できるか
- 遺言が複数見つかったとき、どれが効力を持つか

前身は「民法債権法務士認定試験」で、2018年6月に第1回が行われました。いまの民法法務士は、債権法だけでなく、総則・物権・親族・相続まで範囲を広げた試験です。

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 70問・150分（10:00〜12:45） |
| 合格基準 | 70%以上（問題の難易度により調整し、70%未満でも合格とする場合がある） |
| 受験料 | 一般16,500円／学割13,200円（税込）。民法債権法務士の合格者は11,000円 |
| 追加費用 | CBTは会場費1,500円、オンラインIBTはカメラの往復送料3,000円 |
| 受験方式 | 公開会場（マークシート）・CBT・オンラインIBT |
| 試験日 | 年3回（1月・5月・11月ごろ） |

（出典: 全日本情報学習振興協会「民法法務士認定試験」のページ、2026年10月31日確認）

70問を150分で解くので、1問あたり2分ほどあります。条文の知識に加えて、事例を読んで当てはめる問題に時間を使えます。次回以降の日程は[民法法務士の試験日程](/column/ccc-nittei/)にまとめています。

## 出題範囲

協会が示している出題範囲は次のとおりです。

| 分野 | 主な内容 |
|---|---|
| 民法総則 | 人、法律行為、期間の計算、時効 |
| 物権 | 占有権、所有権、地上権、永小作権など |
| 債権総論 | 債権の目的、債権の効力、多数当事者の債権・債務、債権譲渡など |
| 債権各論 | 総則、売買、消費貸借、使用貸借など |
| 親族 | 婚姻 |
| 相続 | 相続人、相続の効力、相続の承認と放棄、遺言など |

分野ごとの問題数は公表されていません。当サイトでは、民法総則と債権総論・債権各論を2つずつ、物権と親族・相続を1つずつの分野に分け、8分野・各20問の練習問題として並べています。

## 改正点を意識する

民法はここ数年で大きく改正されています。古い教材のまま覚えると、正誤が逆になる論点があります。

- **2020年4月施行の債権法改正**: 消滅時効、法定利率、保証、債権譲渡、定型約款、売主の契約不適合責任など
- **2022年4月施行の成年年齢の引下げ**: 成年は18歳
- **2023年4月施行の物権の改正**: 相隣関係、共有、所有者不明土地・建物の管理など

協会も「改正点を意識して学ぶ」ことを試験の目的に挙げています。教材を選ぶときは、改正後の内容に対応しているかを確かめてください。

## 受けるメリット

合格すると、合格証書と写真入りの認定カードが交付され、名刺などに認定ロゴを使えます。

- 金融・保険・不動産・IT・人材など、契約を扱う仕事で、民法の理解を客観的に示せる
- 行政書士・司法書士・宅建士など、民法が出る国家試験の前に、民法の全体を一通り確かめられる
- 法務・総務の担当者が、改正後の民法を体系的に学び直すきっかけになる

関連する試験として、会社の機関や組織再編を扱う[会社法法務士](/cac/)、労働契約を扱う[労働法務士](/llc/)、取引法務の全体を扱う[ビジネス実務法務検定2級](/bijihou2/)もあります。

## まず何から始めるか

当サイトでは[民法法務士の練習問題](/ccc/)を160問、条文の根拠つきの解説で無料公開しています。最初に、本試験と同じ70問・150分の[模擬試験](/ccc/moshi/)で、どの分野が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[本番形式テスト](/ccc/mock/)が使えます。登録は不要です。

勉強の進め方は[民法法務士の勉強法と勉強時間](/column/ccc-benkyouhou/)、難易度は[民法法務士の合格率と難易度](/column/ccc-goukakuritsu/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
