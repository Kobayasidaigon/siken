企業危機・コンプライアンス管理士認定試験は、80問・120分で、合計70%が合格の目安です。範囲は6つの課題にまたがり、法令から広報・BCPの実務まで幅広く出題されます。この記事では、勉強時間の目安と、広い範囲を効率よく押さえる進め方をまとめます。

試験の全体像は[企業危機・コンプライアンス管理士認定試験とは](/column/ccm-toha/)で整理しています。

## 勉強時間の目安

協会は勉強時間の目安を公表していないので、ここに書くのは当サイトの目安です。

| これまでの経験 | 勉強時間の目安 | 期間の例 |
|---|---|---|
| 法務・内部監査・リスク管理の実務経験がある | 20〜30時間 | 1日1時間で1か月 |
| 総務・広報などで、社内規程や研修に関わったことがある | 30〜35時間 | 1日1時間で1か月〜1か月半 |
| 企業法務やリスク管理を学んだことが無い | 40時間前後 | 1日1時間で1か月半〜2か月 |

範囲が広いぶん、**全部を深くやろうとしない**ことが大事です。第2・第3・第6課題は考え方を一度整理すれば得点が安定し、第1・第5課題は法令の名前と要点を押さえる、という配分が効率的です。

## 教材は「公式テキスト＋問題演習」

- **公式テキスト**: マイナビ出版から公式テキスト（2024年4月発売）が出ています。範囲を一通り押さえる基本の1冊です。発売後の改正（取適法、コーポレートガバナンス・コードの2026年改訂など）は、新しい資料で補ってください。
- **問題演習**: 当サイトの[練習問題160問](/ccm/)と、本番と同じ80問・120分の[模擬試験](/ccm/moshi/)。無料で、登録は要りません。

## 進め方：考え方の課題から入る

### 1. 第2課題「リスクと危機」で土台を作る

最初に取り組むのは第2課題です。ここで覚える用語が、ほかの課題すべての土台になります。

- **リスクの定義**: ISO 31000では「目的に対する不確かさの影響」。よい方向の影響も含む
- **リスクマネジメントのプロセス**: リスクの特定 → 分析 → 評価 → 対応、と、それを支えるコミュニケーション・モニタリング
- **リスク対応の選択肢**: 回避・低減・移転・保有。保険は「移転」、事業からの撤退は「回避」
- **リスクと危機の違い**: リスクは「起こるかもしれない」もの、危機（クライシス）は「すでに起きた・起きつつある」重大な事態

### 2. 第3課題と第6課題は「平時」と「有事」で整理する

第3課題（危機管理体制の構築）と第6課題（自然災害と危機管理）は、**平時に何を準備し、有事に何をするか**で整理すると覚えやすくなります。

| | 平時 | 有事 |
|---|---|---|
| 体制 | リスク管理委員会、規程とマニュアル、報告ルートの決定 | 危機対策本部の設置、権限の集中、情報の一元化 |
| 準備 | 訓練・演習、備蓄、連絡網、代替拠点 | 安否確認、初動対応、重要業務の優先再開 |
| BCP | 重要業務と目標復旧時間（RTO）の決定 | 計画の発動、代替手段での業務継続 |

内部通報制度は、公益通報者保護法の体制整備義務（常時使用する労働者が300人を超える事業者）、従事者の指定、通報者を特定させる情報の守秘を押さえます。2025年の改正（2026年12月1日施行予定）で、通報を理由とする解雇・懲戒に刑事罰が設けられる点も押さえておきます。

### 3. 第4課題「危機管理広報」は「やってはいけない対応」から覚える

危機管理広報は、常識で判断できる部分が多い一方、選択肢に「もっともらしい誤り」が混ざります。

- 事実が確定するまで一切発表しない（→ 分かっている事実と対応を、早く・分かる範囲で出す）
- 記者会見で「ノーコメント」を繰り返す（→ 隠しているという印象を与える）
- 謝罪と同時に、責任を取引先や担当者個人に押しつける
- SNSで批判されたとき、投稿者に反論したり投稿を削除させようとしたりする

あわせて、**ポジションペーパー**（会社の見解をまとめた文書）と**ホールディングステートメント**（詳細が分かる前に出す一次的な声明）の違いも押さえておきます。

### 4. 第1・第5課題は「法令の名前と要点」に絞る

第1課題（企業の社会的責任）と第5課題（企業危機各論）は、法令や制度の名前が多く出てきます。深追いせず、**どの法令が、どんな行為を規制しているか**を表で整理します。

| テーマ | 主な法令・制度 |
|---|---|
| 不正会計・インサイダー取引 | 金融商品取引法 |
| カルテル・入札談合・優越的地位の濫用 | 独占禁止法（課徴金減免制度） |
| 下請取引 | 中小受託取引適正化法（取適法、2026年1月施行。旧下請法） |
| 不当表示 | 景品表示法 |
| 情報漏えい | 個人情報保護法（漏えい等の報告）、不正競争防止法（営業秘密） |
| 製品事故 | 消費生活用製品安全法（重大製品事故の報告） |
| 内部統制・ガバナンス | 会社法、金融商品取引法の内部統制報告制度、コーポレートガバナンス・コード |

名前の変わった法令や、改訂された制度は、**新しい名称・内容で覚える**ことが大事です。

## 6週間のスケジュール例

1日1時間、企業法務を学んだことが無い人を想定した例です。

| 週 | やること |
|---|---|
| 1週目 | 模擬試験で現在地を確認。第2課題「リスクと危機」の20問 |
| 2週目 | 第3課題「危機管理体制の構築」の20問。内部通報制度を整理する |
| 3週目 | 第6課題「自然災害と事業継続」と第4課題「危機管理広報」の40問 |
| 4週目 | 第1課題の40問（社会的責任・ガバナンスと内部統制） |
| 5週目 | 第5課題の40問（不祥事と法令違反・情報漏えいと製品事故）。法令の表を作る |
| 6週目 | 間違えた問題の解き直し。模擬試験をもう一度受け、56問（70%）以上を確認 |

## まとめ

- 勉強時間の目安は、経験に応じて20〜40時間前後。範囲が広いので深追いしない
- 第2課題のリスクマネジメントの用語を土台にする
- 体制とBCPは「平時と有事」、広報は「やってはいけない対応」で整理する
- 法令は名前と要点を表にし、改正後の名称・内容で覚える
