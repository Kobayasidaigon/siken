試験勉強を始めるとき、まず過去問を探す方は多いと思います。企業危機・コンプライアンス管理士認定試験は2024年度に名称が変わった試験で、過去の教材の扱いには少し注意が要ります。この記事では、その事情と、過去問の代わりに何を使えばよいかを整理します。

## 過去問を無料で解ける公式のページは見つからない

**本試験の過去問をまとめて無料で解ける公式のページは、当サイトが調べた範囲では見つかりませんでした**（2026年10月時点）。協会のサイトには、出題のイメージをつかむためのサンプル問題のページがあります。最初に目を通して、問題の形式と難しさの感覚をつかむのに使えます。

## 旧称「企業危機管理士」時代の問題集の注意点

この試験は、2024年度に「企業危機管理士認定試験」から現在の名称に変わりました。旧称の時代の問題集（本試験の形式の問題を収録したもの）も出ています。中身の多くは今も役に立ちますが、使うときは次の点に気をつけてください。

1. **今の6課題の構成と合っているか**を確かめる。現在の課題は、企業の社会的責任／リスクと危機／危機管理体制の構築／危機管理広報／企業危機各論／自然災害と危機管理の6つ
2. **その後の法改正・制度の改訂を補う**。とくに次の4つは、古い教材では旧制度のまま書かれている

| 制度 | 今の内容 |
|---|---|
| 旧下請法 | 2026年1月1日から中小受託取引適正化法（取適法）。用語も「委託事業者」「中小受託事業者」に |
| コーポレートガバナンス・コード | 2026年7月21日に改訂。補充原則が廃止され「解釈指針」が新設、基本原則は4つに |
| 公益通報者保護法 | 2022年施行の改正で体制整備義務（労働者300人超）と従事者の守秘義務。2025年の改正は2026年12月1日施行予定 |
| 内部統制の基準 | 2023年の改訂で、目的の一つが「報告の信頼性」に |

（出典: 全日本情報学習振興協会 公式サイトの試験ページ、各制度の所管官庁・取引所の公表資料をもとに当サイトが整理、2026年10月確認）

## 代わりに使えるもの

### 1. 公式テキスト

マイナビ出版から、現在の名称の公式テキスト（2024年4月発売）が出ています。範囲を体系的に押さえる基本の1冊です。発売後の改正は、上の表のように新しい資料で補ってください。

### 2. 当サイトの練習問題（160問・無料）

当サイトでは[企業危機・コンプライアンス管理士の練習問題](/ccm/)を160問公開しています。本試験の6課題に合わせ、8分野・各20問です。

| 課題 | 分野（各20問） |
|---|---|
| 第1課題 企業の社会的責任 | 企業の社会的責任とESG／コーポレートガバナンスと内部統制 |
| 第2課題 リスクと危機 | リスクと危機 |
| 第3課題 危機管理体制の構築 | 危機管理体制の構築 |
| 第4課題 危機管理広報 | 危機管理広報 |
| 第5課題 企業危機各論 | 企業不祥事と法令違反／情報漏えい・労務・製品事故 |
| 第6課題 自然災害と危機管理 | 自然災害と事業継続 |

取適法、2026年のコーポレートガバナンス・コード改訂、公益通報者保護法の改正予定など、2026年10月時点の制度に合わせています。すべて当サイト編集部が作ったオリジナル問題で、本試験の過去問の転載ではありません。1問ごとに、正解の理由と、ほかの選択肢がなぜ誤りかを解説しています。

### 3. 模擬試験（80問・120分）と本番形式テスト（20問）

本試験と同じ80問・120分の[模擬試験](/ccm/moshi/)は、6つの課題から出題し、合計70%（56問）で判定します。課題ごと・分野ごとの正答率が出るので、弱い課題がすぐに分かります。

時間が取れない日は、20問の[本番形式テスト](/ccm/mock/)で手ごたえを確かめられます。

## 練習問題の使い方

1. **1周目は分野ごとに解く**。似た制度・用語の違いに気づきやすい
2. **正解した問題も解説を読む**。誤りの選択肢の説明に、別の問題で問われる知識が入っている
3. **間違えた問題は、取り違えた点を一言で書く**（例:「リスクの移転と回避を逆に覚えていた」「旧下請法の用語で覚えていた」）
4. **2周目は間違えた問題だけ**を解き直す
5. **最後に模擬試験**で、合計70%を安定して超えるかを確かめる

本試験の問題は、練習問題と同じ文面では出ません。選択肢の言い回しを覚えるのではなく、**なぜその対応・その制度の理解が正しいのかを説明できる状態**を目指してください。

## まとめ

- 過去問をまとめて無料で解ける公式のページは見つからない。協会のサンプル問題で形式をつかむ
- 旧称の時代の問題集は、今の6課題の構成と、その後の法改正を確かめて使う
- 公式テキストで範囲を押さえ、無料の練習問題160問と模擬試験80問で演習量を確保する

勉強の進め方は[企業危機・コンプライアンス管理士の勉強法と勉強時間](/column/ccm-benkyouhou/)、試験日と申込締切は[試験日程](/column/ccm-nittei/)にまとめています。
