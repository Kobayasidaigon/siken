企業危機・コンプライアンス管理士認定試験は、一般財団法人 全日本情報学習振興協会が実施している認定試験です。2024年度に「企業危機管理士認定試験」から名称が変わりました。企業が直面する不祥事や事故、災害などの危機にどう備え、起きたときにどう対応するかを問います。この記事では、試験の形式と出題範囲、受ける意味を整理します。

## どんな試験か

対象は、**総務・法務・広報・人事・内部監査の担当者や管理職**です。問われるのは、たとえば次のような判断です。

- 内部通報があったとき、通報者を守りながら調査を進めるには何が必要か
- 製品の不具合が見つかったとき、誰に・いつまでに報告し、どう公表するか
- 記者会見で謝罪するとき、何を準備し、どんな言い方を避けるべきか
- 大地震で本社が使えなくなったとき、どの業務から再開するか

特定の法律だけを深く問う試験ではなく、**会社法・金融商品取引法・独占禁止法・公益通報者保護法・個人情報保護法**など、危機に関わる法令と、広報やBCPの実務を幅広く扱います。

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施団体 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 80問・120分 |
| 合格基準 | 合計70%以上 |
| 受験料 | 11,000円（税込）、学生 8,800円（税込） |
| 旧称 | 企業危機管理士認定試験（2024年度に改称） |

（出典: 全日本情報学習振興協会 公式サイトの試験ページ、2026年10月確認）

120分で80問なので、1問あたり1分半です。事例を読んで判断する問題が多く、時間には比較的余裕があります。

次回の試験は2027年1月31日（第30回）です。日程は[企業危機・コンプライアンス管理士の試験日程](/column/ccm-nittei/)にまとめています。

## 出題範囲：6つの課題

| 課題 | 名前 | 主な内容 |
|---|---|---|
| 第1課題 | 企業の社会的責任 | CSRとステークホルダー、ESG、ビジネスと人権、コーポレートガバナンス、内部統制 |
| 第2課題 | リスクと危機 | リスクの定義（ISO 31000）、リスクマネジメントのプロセス、リスク対応、リスクと危機の違い |
| 第3課題 | 危機管理体制の構築 | 危機管理の規程とマニュアル、平時と有事の体制、報告ルート、訓練、内部通報制度、第三者委員会 |
| 第4課題 | 危機管理広報 | 初動の情報発信、記者会見、ポジションペーパー、SNSの炎上への対応、適時開示 |
| 第5課題 | 企業危機各論 | 不正会計・品質偽装・カルテルなどの法令違反、情報漏えい、ハラスメント・過重労働、製品事故とリコール |
| 第6課題 | 自然災害と危機管理 | 事業継続計画（BCP）、安否確認、帰宅困難者対策、感染症、サプライチェーンの寸断 |

協会のサンプル問題のページでは、「危機管理広報」は協会にとって新しい分野だと紹介されています。課題ごとの問題数は公表されていません。

当サイトでは、第1課題と第5課題を2つずつ、ほかを1つずつの分野に分け、8分野・各20問の練習問題として並べています。

## 押さえておきたい最近の制度の動き

範囲が広い試験なので、制度が変わった部分は特に注意が要ります。

| 制度 | 動き |
|---|---|
| 下請法 | 2026年1月1日から「中小受託取引適正化法（取適法）」に改正・改称。「親事業者」は「委託事業者」、「下請事業者」は「中小受託事業者」に |
| コーポレートガバナンス・コード | 2026年7月21日に改訂。補充原則が廃止され「解釈指針」が新設、基本原則は5つから4つに |
| 公益通報者保護法 | 2025年の改正が2026年12月1日に施行予定。通報を理由とする解雇・懲戒への刑事罰の新設、一定のフリーランスの保護対象化 |
| 内部統制の基準 | 2023年の改訂で、目的の一つが「財務報告の信頼性」から「報告の信頼性」に |

古い教材や記事は、旧制度のまま書かれていることがあります。教材を選ぶときは、発行時期と、こうした改正への対応を確かめてください。

## 合格基準と難易度

合格の目安は**合計70%以上**です。80問なら56問の正解にあたります。課題ごとの基準は示されていません。

当サイトが調べた範囲では、回ごとの合格率は見つかりませんでした。出題の中身から見ると、

- **第2・第3・第6課題**は、リスクマネジメントやBCPの考え方を一度整理すれば得点しやすい
- **第1・第5課題**は、法令や制度の名前と中身が多く、最近の改正の影響も受けやすい
- **第4課題**は、記者会見やSNS対応の「やってはいけない対応」を見抜く常識的な判断が中心

という性格の試験です。

## 受験に向いている人

- 総務・法務・内部監査で、リスク管理や内部通報制度の運用を担当している人
- 広報担当で、不祥事の際の情報発信を任される可能性がある人
- 管理職として、自部門のコンプライアンスと事業継続に責任を持つ人
- ハラスメントの防止を深く学ぶなら[ハラスメントアドバイザー](/had/)、情報漏えいなら[個人情報保護士](/pii/)も、同じ協会のサイトで申し込める関連の試験

## まず何から始めるか

当サイトでは[企業危機・コンプライアンス管理士の練習問題](/ccm/)を160問、解説つきで無料公開しています。最初に、本試験と同じ80問・120分の[模擬試験](/ccm/moshi/)で、どの課題が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[本番形式テスト](/ccm/mock/)が使えます。登録は不要です。

勉強の進め方は[企業危機・コンプライアンス管理士の勉強法と勉強時間](/column/ccm-benkyouhou/)で、教材と過去問の事情は[過去問は手に入るか](/column/ccm-kakomon/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず協会の公式サイトで最新の案内を確認してください。
