賃貸不動産経営管理士は、賃貸住宅の管理を担う人の知識を証明する国家資格です。2021年に施行された賃貸住宅管理業法によって法律上の位置づけが与えられ、それまでの民間資格から性格が変わりました。この記事では、何をする資格なのか、なぜ必要とされているのか、試験では何が問われるのかを整理します。

## 何をする資格か

賃貸不動産経営管理士は、**大家（賃貸人）から賃貸住宅の管理を委託された管理業者の側に立つ**資格です。入居者の募集から契約、家賃の管理、建物の維持保全、退去時の原状回復までが守備範囲になります。

「不動産の資格」というと宅建士を思い浮かべる方が多いと思いますが、宅建士が扱うのは売買・賃貸の**仲介**です。契約が成立するまでが宅建士、成立した後の長い期間を扱うのが賃貸不動産経営管理士、と分けると輪郭がはっきりします。

## 国家資格化で何が変わったか

大きな転機は2021年6月に全面施行された賃貸住宅管理業法です。この法律で次の2つが定まりました。

1. **賃貸住宅管理業の登録制度**。管理戸数200戸以上の業者は国土交通大臣への登録が義務になりました。
2. **業務管理者の設置義務**。登録した業者は、営業所または事務所ごとに業務管理者を1名以上置かなければなりません。

この業務管理者になるための要件のひとつが、賃貸不動産経営管理士の資格です（一定の実務経験と指定講習の修了が別途必要になります）。つまり、**資格保有者がいないと営業所を開けない**という構造になりました。管理会社にとって、社内に何人いるかが直接事業に効く資格です。

もうひとつの柱がサブリースの規制です。同法では特定賃貸借契約（いわゆるサブリース契約）について、誇大広告の禁止、不当な勧誘の禁止、重要事項説明の義務が定められました。過去にトラブルが相次いだ分野で、試験でも出題の中心になっています。

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施団体 | 賃貸不動産経営管理士協議会 |
| 試験日 | 年1回・11月（令和8年度は2026年11月15日） |
| 出題形式 | 四肢択一・50問・120分 |
| 免除 | 管理士講習の修了者は5問免除（45問で受験） |
| 受験資格 | 制限なし |
| 受験手数料 | 12,000円 |

合格基準点は年度ごとに決まります。令和7年度（2025年度）は50問中38問以上（講習修了者は45問中33問以上）でした。

## 令和7年度の実績

| 項目 | 数値 |
|---|---|
| 受験者数 | 31,792人 |
| 合格者数 | 9,370人 |
| 合格率 | 29.5% |
| 合格基準点 | 38点／50点 |

講習修了者に限ると、受験13,397人・合格4,898人・合格率36.6%でした。5問免除の効果は小さくありません。

（出典: 賃貸不動産経営管理士協議会の試験結果、およびこれを引用する予備校各社の公表値、2026年9月確認）

合格率だけを見ると通りやすそうに見えますが、合格基準点が38点、つまり**8割弱の正答を求められる**点は押さえておく必要があります。合格率29.5%と合格基準76%が同居しているのがこの試験の特徴で、「広く浅く、しかし取りこぼさない」学習が要ります。

## 出題範囲

このサイトでは、出題実績にもとづいて次の10分野に整理しています。

- 賃貸住宅管理業法と登録制度
- 管理受託契約
- サブリースと特定賃貸借契約
- 賃貸借契約と借地借家法
- 契約の終了・更新と原状回復
- 金銭の管理と会計
- 建物の維持保全と設備
- 入居者の募集と広告規制
- 賃貸業への支援業務（税・保険・証券化）
- 賃貸管理の意義と管理士の役割

配点が最も大きいのは賃貸住宅管理業法です。法律そのものが資格の根拠になっているので、当然といえば当然の配分になっています。次いで賃貸借契約と借地借家法、建物の維持保全と設備が続きます。

法律科目と建物・設備の知識が同居しているのがこの試験の難しさで、法学部出身者が設備で、建築系の人が法律で足を取られる、という形になりがちです。

## どんな人が受けているか

- 賃貸管理会社の従業員（業務管理者の要件を満たすため）
- 賃貸仲介と管理を兼ねる不動産会社の社員
- 自分で賃貸物件を持っている、あるいはこれから持つオーナー
- 宅建士を取ったあと、管理側の知識も押さえたい人

宅建士との併願、あるいは同じ年の管理業務主任者（12月実施）との併願も現実的な選択肢です。試験日が3週間差で、申込締切が同じ日である点については[賃貸不動産経営管理士と管理業務主任者の併願](/column/chintai-kangyo-hikaku/)で詳しく整理しています。

## まず何から始めるか

過去問が市販されている試験ですが、賃貸住宅管理業法は施行から日が浅く、法改正の反映が追いついていない教材も混じります。条文ベースで確認しながら進めるのが安全です。

このサイトでは[賃貸不動産経営管理士の練習問題](/chintai/)を200問、根拠条文つきの解説とあわせて公開しています。通しで時間を計りたい場合は本試験と同じ50問・120分の[模擬試験](/chintai/moshi/)、短時間で手ごたえだけ見たい場合は20問で分野別の正答率が出る[本番形式テスト](/chintai/mock/)があります。いずれも登録は不要です。

試験日程・受験手数料・免除の要件は年度ごとに変わります。申込の前に必ず賃貸不動産経営管理士協議会の公式発表をご確認ください。
