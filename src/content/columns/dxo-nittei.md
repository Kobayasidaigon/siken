DXオフィサー認定試験の次回は、2027年1月31日（日）の第17回です。申込は受付中で、**締切は2026年12月24日（木）**です。その次の第18回は2027年5月23日（日）で、この回から受験料が改定されます。この記事では、試験日と申込期間、受験料、申込の流れをまとめます（2026年10月31日時点、全日本情報学習振興協会の公式案内にもとづきます）。

## 試験日程

| 回 | 試験日 | 申込期間 |
|---|---|---|
| 第17回 | **2027年1月31日（日）** | **2026年9月15日（火）〜12月24日（木）** |
| 第18回 | 2027年5月23日（日） | 2026年12月29日（火）〜2027年4月15日（木） |
| 第19回 | 2027年10月17日（日） | 未掲載 |

（出典: 全日本情報学習振興協会「DXオフィサー認定試験」のページと試験日程の一覧、2026年10月31日確認）

## 受験料と試験の形式

| 項目 | 内容 |
|---|---|
| 受験料 | 一般13,200円／学割10,560円（税込）。**2027年5月の回から一般16,500円に改定** |
| 割引 | DX推進アドバイザー認定試験の合格者は受験料が20%割引（昇級特別価格） |
| 問題数 | 4択100問（第1課題30問・第2課題50問・第3課題20問） |
| 試験時間 | 10:00〜12:15 |
| 合格基準 | 70%以上。問題の難易度により調整する場合がある |
| 出題範囲 | 第1課題 DXの現状（DX総論・業種別DX・DX企業の現状）／第2課題 DXの技術（AI・ビッグデータ・IoT・クラウド・その他のIT技術・デジタルマーケティング・情報セキュリティ）／第3課題 DXの展開（DX人材・方法論・制度と政策） |

改定前の受験料で受けられるのは、1月31日の第17回までです。割引の条件と、改定後の学割の額は申込のときの案内で確かめてください。

### DX推進アドバイザーに合格している方へ

DXオフィサーは、[DX推進アドバイザー](/dxa/)の上位にあたる試験です。DX推進アドバイザーの合格者は受験料が20%割引になるので、続けて受けるなら割引を使えるか確認してから申し込んでください。

## 申込の流れ

申込は、全日本情報学習振興協会のDXオフィサー認定試験のページ（https://www.joho-gakushu.or.jp/dx/dxo/ ）から行います。

1. 公式ページで、受験する回と受験方式を選ぶ
2. 案内に沿って、氏名・連絡先などを入力する（割引を使う方は合格者の情報も）
3. 受験料を支払う
4. 試験が近づいたら、届く案内で当日の時間や会場を確認する

対策講座（SMART合格講座）を試験と同時に申し込むと、受験料と講座の合計から3,300円の割引があります（講座のページでは「講座＋試験」で28,600円・税込。受験料の改定後は変わる見込みです）。

## 試験日から逆算して準備する

100問のうち半分の50問が第2課題（技術）です。ここを落とさないことが合格への近道になります。

| 時期（第17回の場合） | やること |
|---|---|
| 11月 | 第1課題（DX総論・業種別の事例）で全体像をつかむ |
| 12月 | 第2課題のAI・ビッグデータ・IoT・クラウド。12月24日の締切までに申込を済ませる |
| 1月前半 | 第2課題のデジタルマーケティングと情報セキュリティ、第3課題（DX人材・制度） |
| 1月後半 | 全体の見直し。用語の取り違えが多い技術分野を重点的に |

試験の概要と分野の分け方は、[DXオフィサーのページ](/dxo/)にまとめています。

試験日程・受験料は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
