DXオフィサー認定試験は、DX（デジタルトランスフォーメーション）を進める立場の人に向けた認定試験です。全日本情報学習振興協会が実施しています。この記事では、何を問う試験なのか、出題範囲と合格基準、同じ協会のDX推進アドバイザーとの違いを整理します（2026年11月1日時点、協会の公式案内にもとづきます）。

## どんな試験か

協会は、この試験を「DXを推進するCDX、CDXO、CDOの方々に必須のDX知識」を学ぶものと説明し、DXの現状・技術・展開の3つの知識を身につけて「各種のマネージャーやオフィサーとして活躍できる人材、あるいはサポートできる人材の養成」をめざすとしています。

問われるのは、たとえば次のような知識です。

- 経済産業省のDX推進指標やデジタルガバナンス・コードが求めていること
- 生成AI・機械学習・IoT・クラウドなどの技術の特徴と使いどころ
- デジタルマーケティングの指標や手法
- DX人材の類型や、DXを進める方法論・制度

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 100問・4択（各1点、100点満点）。開催時間は10:00〜12:15 |
| 合格基準 | 70%以上（問題の難易度により調整する場合がある） |
| 受験料 | 一般13,200円／学割10,560円（税込）。2027年5月の回から一般16,500円に改定 |
| 割引 | DX推進アドバイザーの合格者は昇級特別割引、資格者部会の会員は20%割引 |
| 追加費用 | CBTは会場費1,500円、オンラインIBTはカメラの往復送料3,000円 |
| 受験方式 | 公開会場（マークシート）・CBT・オンラインIBT |
| 試験日 | 年3回（1月・5月・10月ごろ） |

（出典: 全日本情報学習振興協会「DXオフィサー認定試験」のページ、2026年10月31日確認）

次回以降の日程は[DXオフィサーの試験日程](/column/dxo-nittei/)にまとめています。

## 出題範囲：3つの課題

| 課題 | 問題数 | 内容 |
|---|---|---|
| 第1課題 DXの現状 | 30問 | DX総論、業種別DXビジネスの現状、DX企業の現状 |
| 第2課題 DXの技術 | 50問 | AI、ビッグデータ、IoT、クラウド、その他のIT技術、デジタルマーケティング、情報セキュリティ |
| 第3課題 DXの展開 | 20問 | DX人材、DXの方法論、DX関連の制度・政策 |

半分の50問が第2課題の技術です。当サイトでは、第1課題を2つ、第2課題を5つ、第3課題を1つの分野に分け、8分野・各20問の練習問題として並べています。

## DX推進アドバイザーとの違い

同じ協会のDX推進アドバイザー認定試験と、DXオフィサー認定試験の違いは次のとおりです（どちらも2026年10月時点の協会の案内による）。

| 項目 | DX推進アドバイザー | DXオフィサー |
|---|---|---|
| 問題数 | 100問（2択35問＋4択65問） | 100問（すべて4択） |
| 課題の配分 | 現状40・技術50・展開10 | 現状30・技術50・展開20 |
| 合格基準 | 70% | 70% |
| 受験料（一般） | 11,000円 | 13,200円 |

DXオフィサーは、すべてが4択になり、第3課題（DX人材・方法論・制度）の比重が大きくなっています。DX推進アドバイザーの合格者には昇級特別割引があり、協会もDX推進アドバイザーの次の資格として位置づけています。

## 改訂の多い資料に注意する

DXの分野では、国の指針や標準がよく改訂されます。2026年10月時点で押さえておきたいのは次のような点です。

- 経済産業省・IPAの**DX推進指標**（2026年2月改訂）
- 総務省・経済産業省の**AI事業者ガイドライン**（第1.2版、2026年3月）
- **デジタルスキル標準 ver.2.0**（2026年4月。DX推進スキル標準の人材類型は6つ）

古い資料のまま覚えると、正誤が逆になる論点があります。

## 受けるメリット

合格すると、合格証書と写真入りの認定カードが交付され、名刺などに認定ロゴを使えます。

- DX推進の担当者・管理職が、技術と経営の両方の知識を体系的に確かめられる
- DX推進アドバイザーの次の目標として、より実践的な範囲まで学べる
- 社内でDX人材を育てるときの、共通の物差しになる

関連する試験として、[DX推進アドバイザー](/dxa/)、[AI活用アドバイザー](/aia/)、[情報・サイバーセキュリティ管理士](/isec/)もあります。

## まず何から始めるか

当サイトでは[DXオフィサーの練習問題](/dxo/)を160問、出典つきの解説で無料公開しています。最初に、本試験と同じ100問の[模擬試験](/dxo/moshi/)で、どの課題が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[腕試しテスト](/dxo/mock/)が使えます。登録は不要です。

勉強の進め方は[DXオフィサーの勉強法と勉強時間](/column/dxo-benkyouhou/)、難易度は[DXオフィサーの合格率と難易度](/column/dxo-goukakuritsu/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
