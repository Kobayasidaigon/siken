DXパスポート試験は、一般財団法人 全日本情報学習振興協会が実施している、DX（デジタルトランスフォーメーション）の基礎知識を問う試験です。DXとは何か、各業界で何が起きているのか、DXを支えるAIやクラウドなどの技術がどういうものかを、技術者ではない人向けの範囲で問います。この記事では、試験の形式と配点、出題範囲、名前の似た制度との違いを整理します。

## どんな試験か

DXパスポート試験は、**DXを「進める側」の基礎知識**を確かめる試験です。プログラミングやシステム設計は問われません。問われるのは次のような知識です。

- DXの定義と、紙の電子化（デジタイゼーション）や業務の効率化（デジタライゼーション）との違い
- 経済産業省の「DXレポート」や「デジタルガバナンス・コード」など、国の施策
- 金融・小売・製造・物流・医療・行政など、業種ごとのDXの事例
- AI・ビッグデータ・IoT・クラウド・情報セキュリティの基本的な仕組みと用語

営業・企画・管理部門など、DXの推進に関わる部署の人や、就職活動を控えた学生に向いた内容です。

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施団体 | 一般財団法人 全日本情報学習振興協会 |
| 問題数・時間 | 60問・60分 |
| 出題形式 | 2択30問・4択30問（各課題30問のうち2択15問・4択15問） |
| 配点 | 2択問題 計120点・4択問題 計240点（合計360点） |
| 合格基準 | 70%以上の得点（問題の難易度により調整される場合がある） |
| 受験料 | 9,350円（税込） |

（出典: 全日本情報学習振興協会 公式サイトのDXパスポート試験のページ、同協会のSMART合格講座のページ、2026年10月確認）

次回の試験は2027年1月31日（第19回）です。日程と申込期間は[DXパスポート試験の試験日程](/column/dxp-nittei/)にまとめています。

## 出題範囲：2つの課題

| 課題 | 章 | 主な内容 |
|---|---|---|
| 第1課題 DXの現状 | DX総論 | DXの定義、DXレポートと「2025年の崖」、レガシーシステム、デジタルガバナンス・コード、DX認定制度 |
| | 業種別DXビジネスの現状 | フィンテックとキャッシュレス決済、小売のOMO、スマートファクトリー、MaaS、行政のデジタル化、GIGAスクール構想 |
| | DX企業の現状 | プラットフォームビジネス、サブスクリプション、シェアリングエコノミー、デジタルディスラプション |
| 第2課題 DXの技術 | AI | 機械学習の3つの方式、ディープラーニング、生成AIと大規模言語モデル、AIの倫理 |
| | ビッグデータ | ビッグデータの特徴、構造化・非構造化データ、データの収集と分析、データウェアハウスとデータレイク、オープンデータ |
| | IoT | センサーとアクチュエータ、エッジコンピューティング、5GとLPWA、デジタルツイン |
| | クラウド | クラウドの5つの特徴、SaaS・PaaS・IaaS、パブリック・プライベート・ハイブリッド、責任共有モデル |
| | 情報セキュリティ | マルウェアとランサムウェア、フィッシング、多要素認証、暗号化、ゼロトラスト |

第1課題は**用語と事例の知識**、第2課題は**技術の仕組みを言葉で説明できるか**が中心です。

当サイトでは、上の8つの章をそれぞれ1分野として、各20問の練習問題を並べています。

## 配点：4択は2択の2倍

DXパスポート試験の特徴は、**2択と4択で配点が違う**ことです。2択30問で計120点、4択30問で計240点なので、1問あたり**2択は4点、4択は8点**になります。合計360点のうち、3分の2を4択が占めます。

合格の目安の70%は、360点満点で252点です。たとえば次のような計算になります。

| 2択の正解数 | 2択の得点 | 252点に必要な4択の正解数 |
|---|---|---|
| 30問（全問） | 120点 | 17問（136点） |
| 27問 | 108点 | 18問（144点） |
| 24問 | 96点 | 20問（160点） |

2択は正解しやすい一方で、1問の重みは4択の半分です。**4択の正解が16問以下だと、2択を全問正解しても252点に届きません**。4択の正答率を上げることが合格への近道です。

協会の案内では、合格基準は試験全体での70%で、課題ごとの基準は示されていません。ただ、片方の課題が極端に低いと全体の70%にも届きにくいので、両方の課題で7割を目標にするのが安全です。

## 難易度

当サイトが調べた範囲では、回ごとの合格率は公表されていません。出題の中身から見ると、

- **第1課題**は、ニュースや社内の取り組みでDXに触れている人なら、用語を覚えれば得点しやすい
- **第2課題**は、ITに苦手意識がある人にとっての山場。とくにAIとクラウドは、似た用語の区別（教師あり学習と教師なし学習、IaaSとSaaS など）が問われる

という性格の試験です。60問・60分で、1問あたり1分。2択は短時間で答え、4択に時間を回すのが基本の配分です。

## 「DX推進パスポート」とは別のもの

名前が似ていますが、**DX推進パスポート**は別の制度です。DX推進パスポートは、デジタルリテラシー協議会が発行するデジタルバッジで、ITパスポート試験・データサイエンティスト検定（リテラシーレベル）・G検定のうち、合格した試験の数に応じて発行されます。DXパスポート試験は、この対象の3試験には含まれていません。

また、他の団体が実施している「DX検定」などの試験とも別物です。申込や教材選びのときは、**実施団体が全日本情報学習振興協会であること**を確かめてください。

ITパスポート試験との違いは[DXパスポートとITパスポートの違い](/column/dxp-itpass-hikaku/)で詳しく比べています。

協会の編集部が編集した公式テキストが、マイナビ出版から出ています（2024年8月発売）。範囲を一通り読むならこれが基本の1冊です。

当サイトでは[DXパスポート試験の練習問題](/dxp/)を160問（2択80問・4択80問）、解説つきで無料公開しています。本試験と同じ60問・60分の[模擬試験](/dxp/moshi/)と、20問の[本番形式テスト](/dxp/mock/)も、登録なしで受けられます。
