ハラスメントアドバイザー認定試験は、60問・90分で、正答率70%が合格の目安です。この記事では、勉強時間の目安と、5つの課題をどの順番で、どう押さえるかをまとめます。

試験の全体像は[ハラスメントアドバイザー認定試験とは](/column/had-toha/)で整理しています。

## 勉強時間の目安

公式の目安は公表されていないので、ここに書くのは当サイトの目安です。

| これまでの経験 | 勉強時間の目安 | 期間の例 |
|---|---|---|
| 人事・労務の実務経験がある、社労士などの勉強をしたことがある | 15〜20時間 | 1日1時間で3週間 |
| 管理職として研修を受けた程度 | 20〜25時間 | 1日1時間で1か月 |
| 労働法を学んだことが無い | 30時間前後 | 1日1時間で1か月〜1か月半 |

差がつくのは、法律と指針の細かい区別が問われる**課題Ⅱ（法的責任等）と課題Ⅲ（雇用管理上講ずべき措置等）**です。課題Ⅳ・Ⅴは常識で判断できる部分が多く、短い時間で得点を伸ばせます。

## 課題ごとの進め方

### 課題Ⅰ：まず「型」を覚える

最初に取り組むのは課題Ⅰ（ハラスメントの理解）です。ここで覚える型が、ほかの課題の事例問題を読む土台になります。

**パワハラの3つの要素**（すべて満たすものがパワハラ）

1. 優越的な関係を背景とした言動
2. 業務上必要かつ相当な範囲を超えたもの
3. 労働者の就業環境が害されるもの

**パワハラの6つの類型**

| 類型 | 例 |
|---|---|
| 身体的な攻撃 | 殴る、物を投げつける |
| 精神的な攻撃 | 人格を否定する発言、大勢の前での長時間の叱責 |
| 人間関係からの切り離し | 1人だけ別室に隔離する、無視する |
| 過大な要求 | 到底できない量の仕事を押しつける |
| 過小な要求 | 能力とかけ離れた単純作業だけを命じる |
| 個の侵害 | 私生活に過度に立ち入る、性的指向などを本人の了解なく暴露する |

試験では「どの類型か」だけでなく、**「該当しない例」**もよく問われます。たとえば、遅刻を繰り返す部下に一定程度強く注意することは、ただちにパワハラにはあたりません。「優越的な関係」には、上司から部下だけでなく、業務に必要な知識を持つ部下から上司への言動も含まれる点も押さえておきます。

セクハラは**対価型**（拒否したことで不利益を受ける）と**環境型**（就業環境が不快なものになる）、マタハラは**制度等の利用への嫌がらせ型**と**状態への嫌がらせ型**の区別が基本です。

### 課題Ⅲ：措置義務は「4つの柱」で整理する

課題Ⅱより先に、課題Ⅲ（雇用管理上講ずべき措置等）に進むのがおすすめです。事業主が講ずべき措置は、指針で次のように整理されています。

1. 事業主の方針の明確化と、その周知・啓発
2. 相談に応じ、適切に対応するために必要な体制の整備
3. 職場におけるハラスメントへの事後の迅速かつ適切な対応
4. あわせて講ずべき措置（相談者・行為者のプライバシーの保護、相談したことなどを理由とする不利益取扱いの禁止と、その周知）

問題では、ある取組が**どの柱に入るか**や、**義務なのか「望ましい取組」なのか**が問われます。たとえば、相談窓口をセクハラ・パワハラなどで一元的に受け付けることは、指針では望ましい取組とされています。

### 課題Ⅱ：責任の種類を区別する

課題Ⅱ（法的責任等）は、誰が・どんな根拠で・どんな責任を負うかを区別します。

| 誰が | 責任 | 根拠 |
|---|---|---|
| 行為者 | 損害賠償（不法行為） | 民法709条 |
| 行為者 | 刑事責任 | 暴行・傷害・名誉毀損・侮辱・不同意わいせつなど |
| 会社 | 使用者責任 | 民法715条 |
| 会社 | 安全配慮義務違反（債務不履行） | 労働契約法5条など |

懲戒処分では、**就業規則に定めがあること**、**弁明の機会を与えること**、**処分が重すぎないこと（懲戒権の濫用にあたらないこと）**、**減給の限度（労働基準法91条）**がよく問われます。

### 課題Ⅳ・Ⅴ：「善意でもしてはいけない対応」を見抜く

課題Ⅳ（予防・再発防止）と課題Ⅴ（相談業務）は、実務の進め方が中心です。選択肢には、一見すると親切に見えても誤りの対応が混ざっています。

- 相談者の了解を得ずに、行為者に相談の内容を伝える
- 「あなたにも原因があったのでは」と相談者に言う（二次被害）
- 事実確認をしないまま、行為者に処分を言い渡す
- 相談者と行為者を同じ場に呼んで話し合わせる

迷ったら、**相談者の意向とプライバシーを守り、事実確認をしてから措置をとる**という順番に照らして判断すると、正解を選びやすくなります。

## 4週間のスケジュール例

1日1時間、労働法を学んだことが無い人を想定した例です。

| 週 | やること |
|---|---|
| 1週目 | 模擬試験で現在地を確認。課題Ⅰの練習問題40問（パワハラ・セクハラなど） |
| 2週目 | 課題Ⅲの40問。措置義務の4つの柱を自分でまとめる |
| 3週目 | 課題Ⅱの40問。責任の表と懲戒の要件を整理する |
| 4週目 | 課題Ⅳ・Ⅴの40問。間違えた問題を解き直し、模擬試験で42問（70%）以上を確認 |

## まとめ

- 勉強時間の目安は、経験に応じて15〜30時間前後。差がつくのは課題Ⅱ・Ⅲ
- 課題Ⅰでパワハラの3要素・6類型、セクハラ・マタハラの型を先に覚える
- 措置義務は4つの柱と「義務か望ましい取組か」で整理する
- 相談業務は「意向とプライバシーを守り、事実確認をしてから措置」の順番で判断する
