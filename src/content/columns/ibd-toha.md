インバウンド実務主任者認定試験は、訪日外国人の受入れに関わる知識を問う認定試験です。全日本情報学習振興協会が2017年から実施しています。この記事では、何を問う試験なのか、出題範囲と合格基準、受けるメリットを整理します（2026年11月1日時点、協会の公式案内にもとづきます）。

## どんな試験か

協会は、この試験を通じて「インバウンドの現状と動向、インバウンドビジネスの実際と対策、集客、訪日外国人の理解と対応、ニューツーリズムや観光まちづくり」を学べるとしています。対象は、インバウンドビジネスに携わる人です。

問われるのは、たとえば次のような知識です。

- 訪日外国人旅行者数や旅行消費額の動き、国・地域別の特徴
- 免税制度（2026年11月1日からリファンド方式）の仕組み
- 宗教や食習慣（ハラール・ベジタリアンなど）への配慮
- 災害時の外国人旅行者への情報提供

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 87問・120分 |
| 配点 | 課題1〜12の84問が各1点、課題13の3問が各2点（90点満点） |
| 合格基準 | 72点以上（正答率80%） |
| 受験料 | 一般11,000円／学割8,800円（税込）。2027年4月の回から一般14,300円に改定 |
| 追加費用 | CBTは会場費1,500円、オンラインIBTはカメラの往復送料3,000円 |
| 受験方式 | 公開会場（マークシート）・CBT・オンラインIBT |
| 試験日 | 年4回（1月・4月・8月・12月ごろ） |

（出典: 全日本情報学習振興協会「インバウンド実務主任者認定試験」のページ、2026年10月31日確認）

### 外国語検定を持っていれば6点加算

協会が指定する外国語検定を持っている人は、申請すると**総合点に6点が加算**されます。対象は、英語なら英検2級以上・TOEIC L&R 600点以上・TOEFL iBT 62点以上・国連英検B級以上、中国語なら中国語検定3級以上・HSK3級以上、韓国語ならハングル能力検定3級以上・TOPIK3級以上などです（ほかにドイツ語・フランス語・スペイン語・イタリア語・ロシア語・タイ語・インドネシア語の検定も対象）。

申請は**試験の申込のときに**行い、申込完了後に届くメールに証明書の写しを添付して返送します。**申込締切の翌日10時までに書類が確認できないと「加点なし」**になり、申込のあとで加点の有無は変えられません。（出典: 全日本情報学習振興協会「加点制度」のページ、2026年11月1日確認）

次回以降の日程は[インバウンド実務主任者の試験日程](/column/ibd-nittei/)にまとめています。

## 出題範囲：13の課題

| 課題 | 名前 |
|---|---|
| 第1課題 | 観光総論 |
| 第2課題 | インバウンド総論 |
| 第3課題 | インバウンドの現状と動向 |
| 第4課題 | インバウンドと消費 |
| 第5課題 | インバウンドとビジネス |
| 第6課題 | インバウンドとニューツーリズム |
| 第7課題 | 訪日外国人の理解 |
| 第8課題 | 訪日外国人への対応 |
| 第9課題 | インバウンドの集客 |
| 第10課題 | インバウンドとテーマ別観光まちづくり |

| 第12課題 | アフターコロナのインバウンド |

課題ごとの問題数は公表されていません（課題13だけ3問・各2点と示されています）。当サイトでは、13の課題を8つの分野にまとめ、各20問の練習問題として並べています。

## 合格基準が高い

ほかの協会の試験の多くは70%が合格の目安ですが、この試験は**80%（90点満点中72点）**です。課題13の3問（6点）を落とすと、残りの84問で72点、つまり**約86%**の正解が必要になります。苦手な課題を残したままでは届きにくい試験です。

## 数字は時点を意識する

訪日外国人旅行者数（2025年は42,683,301人、日本政府観光局の確定値）や旅行消費額のように、毎年変わる数字が出題の材料になります。免税制度も2026年11月1日にリファンド方式に変わりました。教材や記事を読むときは、**いつ時点の数字か**を確かめる習慣をつけてください。

## 受けるメリット

合格すると、合格証書と写真入りの認定カードが交付され、名刺などに認定ロゴを使えます。

- 宿泊・飲食・小売・交通・観光業で訪日客に接する人が、受入れの知識を体系的に確かめられる
- 自治体や観光協会の担当者が、観光まちづくりや集客の考え方を整理できる
- 社内でインバウンド対応の担当者を育てるときの目標になる

関連する試験として、デジタルを使った集客や業務の変革を扱う[DXオフィサー](/dxo/)、経営と管理の基本を扱う[ビジネスマネジャー検定](/bijimane/)もあります。

## まず何から始めるか

当サイトでは[インバウンド実務主任者の練習問題](/ibd/)を160問、出典つきの解説で無料公開しています。最初に、87問・120分の[模擬試験](/ibd/moshi/)で、どの分野が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[腕試しテスト](/ibd/mock/)が使えます。登録は不要です。

勉強の進め方は[インバウンド実務主任者の勉強法と勉強時間](/column/ibd-benkyouhou/)、難易度は[インバウンド実務主任者の合格率と難易度](/column/ibd-goukakuritsu/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
