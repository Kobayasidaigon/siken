情報・サイバーセキュリティ初級認定試験と情報・サイバーセキュリティ管理士認定試験は、どちらも一般財団法人 全日本情報学習振興協会が実施する情報セキュリティの認定試験です。名前も課題名も似ていますが、問題数や問われる深さははっきり違います。この記事では2つの試験を比べ、どちらから受けるとよいかを整理します。

## ひとことで言うと

- **初級**は、職場で情報を扱う一人ひとりが「何に気をつければよいか」を問う入門の試験です。コンピュータとネットワークの基礎も出題されます。
- **管理士**は、組織として情報セキュリティを「どう管理し、サイバー攻撃にどう備えるか」を、より深く、より多くの問題で問う試験です。

## 試験の比較表

| 項目 | 初級 | 管理士 |
|---|---|---|
| 正式名称 | 情報・サイバーセキュリティ初級認定試験 | 情報・サイバーセキュリティ管理士認定試験 |
| 旧称 | 情報セキュリティ初級認定試験 | 情報セキュリティ管理士認定試験 |
| 問題数・時間 | 80問・60分（1問45秒） | 180問・120分（1問40秒） |
| 課題 | 課題Ⅰ〜Ⅳの4つ | 課題Ⅰ〜Ⅲの3つ |
| 合格基準 | 正答率70%以上 | 正答率70%以上 |
| 受験料（税込） | 8,800円 | 11,000円（学生 8,800円） |
| 試験日 | 年4回（2月・5月・8月・11月）、管理士と同じ日 | 年4回（2月・5月・8月・11月）、初級と同じ日 |

（出典: 全日本情報学習振興協会 公式サイトの試験ページ・試験日程、2026年10月確認）

合格基準はどちらも正答率70%で、問題の難易度によって調整される場合があると案内されています。初級は、協会のSMART合格講座のページで「課題Ⅰ〜Ⅳの各々で70%以上」と案内されているので、課題ごとに7割を取る前提で準備するのが安全です。

## 出題範囲の違い

| 課題 | 初級 | 管理士 |
|---|---|---|
| 課題Ⅰ 情報セキュリティ総論 | 出題される | 出題される（より深く） |
| 課題Ⅱ 脅威と情報セキュリティ対策 | 出題される | 出題される（より深く） |
| 課題Ⅲ サイバーセキュリティ対策 | 出題される | 出題される（より深く） |
| 課題Ⅳ コンピュータの一般知識 | 出題される | **出題されない** |

2026年2月の試験から、管理士の範囲は課題Ⅰ〜Ⅲになり、課題Ⅳ「コンピュータの一般知識」は初級だけの範囲になりました。課題Ⅰ〜Ⅲは名前が同じでも、問われる深さが違います。たとえば次のような差があります。

| テーマ | 初級で問われやすいこと | 管理士で加わること |
|---|---|---|
| リスク管理 | 情報資産、機密性・完全性・可用性の意味 | リスクアセスメントの手順、リスク対応の4分類、ISMSの運用 |
| 法律 | どの行為が不正アクセスにあたるか | 法律ごとの要件の違い、個人情報の漏えい等報告 |
| 攻撃と対策 | フィッシングや標的型攻撃メールに気づく | Webへの攻撃、IDS・IPS・WAFの違い、ゼロトラスト、インシデント対応の手順 |

（当サイトの練習問題の範囲から整理したもので、本試験の出題を保証するものではありません）

## 問題数と時間の違い

初級は80問・60分で1問45秒、管理士は180問・120分で1問40秒です。1問あたりの時間は大きく変わりませんが、**管理士は120分間、集中を保って180問をマークし続ける**必要があります。問題数が2倍以上あるぶん、知識の抜けも点数に出やすくなります。

## 回次の数え方に注意

2つの試験は同じ日に実施されますが、回次の数え方が違います。2026年11月29日の回は、**初級では第64回、管理士では第63回**です。申込のときは、試験の種類と回次を取り違えないようにしてください。日程の詳細は[初級の試験日程](/column/isf-nittei/)と[管理士の試験日程](/column/isec-nittei/)にまとめています。

## どちらから受けるか

| 状況 | おすすめ |
|---|---|
| 情報セキュリティを初めて学ぶ、新入社員・事務職 | 初級 |
| ITの仕組み（記憶装置・ネットワーク・暗号など）の基礎も一緒に学びたい | 初級 |
| 社内でセキュリティの担当・推進役を任されている | 管理士 |
| ITパスポートや初級に合格していて、次の段階に進みたい | 管理士 |
| 個人情報保護士など、協会の上位の試験とあわせて取りたい | 管理士 |

迷ったら、**まず当サイトの模擬試験を両方受けてみる**のが手早い判断方法です。初級の模擬試験で7割を楽に超えるなら、管理士から受けることを考えてよいでしょう。初級の課題Ⅰ〜Ⅲで7割に届かないなら、初級から始めるほうが確実です。

両方を受ける場合は、初級 → 管理士の順がおすすめです。初級で身につけた課題Ⅰ〜Ⅲの土台に、管理の仕組みとサイバー攻撃への対策を上乗せする形で、管理士の準備を短くできます。
