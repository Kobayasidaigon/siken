ITパスポートは、**独学で合格できる試験です**。合格率は令和6年度で49.1%、IT系の国家試験としては入口にあたる難易度で、通信講座に頼らず受かっている人が大勢います。ただし「誰でも自然に受かる」わけではなく、独学でつまずく人には共通のパターンがあります。この記事では、無料で揃う教材の組み合わせと、その分かれ目を整理します。

## 無料で揃う教材の組み合わせ

費用をかけずに始めるなら、次の3つで足ります。

### 1. IPAの公開問題（無料）

実施団体のIPAが、実際に出題した問題を**年度あたり100問**公開しています。本番と同じ形式・同じ分量なので、まずこれで自分の現在地を測ります。

- [IPA 独立行政法人 情報処理推進機構（試験情報）](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)

### 2. シラバス（無料）

出題範囲の一覧です。用語がそのまま並んでいるので、**知らない用語を洗い出すチェックリスト**として使えます。生成AIやDX関連の用語も追加されているので、古い教材だけで進めると抜けが出ます。

### 3. 解説つきの練習問題（無料）

公開問題には解答例はありますが、**誤りの選択肢がなぜ誤りなのかは書かれていません**。ITパスポートは似た用語の区別を問う出題が多いため、ここが埋まらないと本番で迷います。

当サイトでは、シラバスにもとづく練習問題200問を全問解説つきで無料公開しています。本試験の出題比率に合わせてストラテジ系70問・マネジメント系40問・テクノロジ系90問に配分し、10分野に分けてあります。

[ITパスポートの無料練習問題を見る（10分野・200問）](/itpass/)

## 勉強時間の目安

- IT・情報系の基礎がある人：**100〜150時間**（1日2時間で1.5〜2か月）
- まったくの初学者：**180時間程度**

CBT方式で通年実施なので、いつでも受けられます。だからこそ、**先に受験日を予約してから逆算する**ほうが結果的に短く済みます。「準備ができたら申し込む」は、たいてい先延ばしになります。

## 独学でつまずく人の分かれ目

### 分かれ目1：テクノロジ系から始めてしまう

「IT試験だから技術から」と考えて、ネットワークやセキュリティから手をつける人が多いのですが、これは遠回りです。

ITパスポートは**技術以外が55問**（ストラテジ系35問＋マネジメント系20問）を占めます。しかも経営・法務は日本語で意味が取りやすく、暗記が素直に得点になります。**ストラテジ系から始めて土台を作る**ほうが、結果的にテクノロジ系の文章も読みやすくなります。

### 分かれ目2：分野別評価点を知らない

総合評価点が600点を超えていても、**3分野のどれか1つでも300点を下回ると不合格**です。得意分野で稼いで苦手を捨てる戦い方ができません。

独学だとこの基準を知らないまま「合計で6割取れればいい」と考えてしまいがちです。得意分野を700点にするより、**300点を切りそうな分野を450点まで引き上げる**ほうが合格には確実に効きます。

### 分かれ目3：似た用語を「見たことがある」で止める

ITパスポートで最も落としやすいのが、紛らわしい略語の区別です。

| 混同しやすい組み合わせ | 違い |
|---|---|
| SaaS / PaaS / IaaS | 事業者がどこまで提供するか |
| RFI / RFP / RFQ | 情報提供依頼 → 提案依頼 → 見積依頼の順序 |
| SLA / SLM | 合意した文書と、それを維持する活動 |
| インシデント管理 / 問題管理 | 早期復旧か、根本原因の究明か |
| RTO / RPO | いつまでに復旧するか、どの時点まで戻すか |
| 共通鍵暗号 / 公開鍵暗号 | 鍵が同じか、対になっているか |

これらは**違いを一言で言えるか**が基準です。言えないまま次に進むと、本番で選択肢に両方並んだときに手が止まります。

### 分かれ目4：公開問題1年度分だけで満足する

年100問しか公開されないため、1年度分を解くと「本番1回分を通しで解いた」だけになります。分野ごとに繰り返し演習する量には足りません。**間違えた分野を別の教材で厚く回す**工程が要ります。

## 独学の進め方

1. **公開問題を1年度分（100問）解く。** 3分野それぞれの手応えを記録します。
2. **ストラテジ系から潰す。** 用語の意味が取りやすく、最初の得点源になります。
3. **マネジメント系を次に。** 20問と少ないので短期間で仕上がります。似た用語の対比が中心です。
4. **テクノロジ系に時間を投下する。** 45問と最大分量。特に情報セキュリティは出題比重が高い領域です。
5. **もう1年度分の公開問題を通しで解く。** 120分の時間感覚も一緒に確認します。

## 通信講座を検討したほうがよい場合

独学で問題ないのが基本ですが、次に当てはまるなら講座を検討する価値があります。

- 会社から期限を切られていて、**確実に一発で通したい**
- ITにまったく触れたことがなく、**用語の海で心が折れそう**
- 学習の順序を自分で組むより、**カリキュラムに乗ったほうが続く**

いずれも「独学では無理」ではなく「時間を金で買う」判断です。
