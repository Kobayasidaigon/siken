管理業務主任者は、分譲マンションの管理を受託する会社に置くことが義務づけられている国家資格です。名前の似た「マンション管理士」と混同されやすいのですが、立っている側が逆です。この記事では、何をする資格なのか、独占業務は何か、試験では何が問われるのかを整理します。

## 何をする資格か

分譲マンションには、区分所有者で構成する**管理組合**があります。多くの組合は、日常の管理業務を管理会社に委託しています。管理業務主任者は、その**委託を受ける管理会社の側**に立つ資格です。

マンション管理適正化法により、管理業者は事務所ごとに、管理事務を受託している組合数に応じた人数（30組合につき1名以上）の管理業務主任者を置かなければなりません。人がいなければ受託できる組合数が頭打ちになるため、管理会社にとっては事業規模を直接左右する資格です。

## 独占業務

管理業務主任者でなければできない業務が4つあります。

1. **管理委託契約の重要事項の説明**
2. **重要事項説明書への記名**
3. **管理委託契約書への記名**
4. **管理事務の報告**（組合に対して、管理の状況を毎年報告する）

いずれも、管理組合という素人の集まりに対して、専門家が説明責任を果たすための仕組みです。宅建士の重要事項説明と構造が似ています。

## マンション管理士との違い

同じ日に受験案内が並ぶこともあって混同されますが、**立場が反対**です。

| | 管理業務主任者 | マンション管理士 |
|---|---|---|
| 立場 | 管理会社（受託する側） | 管理組合の相談相手（委託する側を助ける） |
| 設置義務 | あり（事務所ごと） | なし |
| 独占業務 | あり（上記4つ） | なし（名称独占） |
| 試験日 | 12月上旬 | 11月下旬 |

マンション管理士は組合の顧問として助言する立場で、独立開業型の資格です。管理業務主任者は会社に所属して実務を回す資格、と考えると分かりやすくなります。

なお、**マンション管理士試験の合格者は、管理業務主任者試験で5問が免除されます**。両方を狙う人は、先にマンション管理士を受けておくと有利になる設計です。

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施団体 | マンション管理業協会 |
| 試験日 | 年1回・12月第1日曜（令和8年度は2026年12月6日 13:00〜15:00） |
| 出題形式 | 四肢択一・50問・120分 |
| 免除 | マンション管理士試験の合格者は5問免除（45問で受験） |
| 受験資格 | 制限なし |
| 受験手数料 | 8,900円（非課税。別途 事務手数料297円） |
| 試験地 | 北海道・宮城・東京・愛知・大阪・広島・福岡・沖縄および周辺地域 |

合格基準点は年度ごとに決まります。令和7年度（2025年度）は50問中36問以上（一部免除者は45問中31問以上）でした。

## 令和7年度の実績

| 項目 | 数値 |
|---|---|
| 受験者数 | 14,435人 |
| 合格者数 | 2,832人 |
| 合格率 | 19.6% |
| 合格基準点 | 36点／50点 |

前年度（令和6年度）は受験14,850人・合格3,159人で、合格点は38点でした。**合格点が2点下がっている**点は、問題が難化した年だったことを示唆します。

（出典: マンション管理業協会の試験結果、およびこれを引用する予備校各社の公表値、2026年9月確認）

合格率は20%を切りますが、受験者の多くが管理会社の実務経験者である点は考慮に入れる必要があります。母集団が絞られたうえでの2割なので、体感の難易度は数字より高めに出ます。

## 出題範囲

このサイトでは、出題実績にもとづいて次の10分野に整理しています。

- 区分所有法（専有部分・共用部分・敷地・管理者）
- 区分所有法（集会・規約・義務違反・復旧建替え）
- マンション標準管理規約
- 管理委託契約と標準管理委託契約書
- 民法と関連法令
- 管理組合の会計と仕訳
- マンション管理適正化法
- 建物の構造と維持保全
- 建築設備
- 建築関連法規とその他

最頻出は**区分所有法と標準管理規約**で、この2つで50問中15問前後を占めます。ここを落とすと合格点に届きません。

特徴的なのは**会計と仕訳**が出ることです。管理組合の予算・決算を扱う立場なので、簿記の初歩にあたる知識が問われます。法律科目に強い人がここで落とすパターンがよくあります。逆に、簿記の学習経験がある人には得点源になります。

## どんな人が受けているか

- マンション管理会社のフロント担当者（設置義務があるため会社から求められる）
- 管理会社への転職を考えている人
- 自分の住むマンションの管理組合で理事を務めている区分所有者
- マンション管理士とあわせて狙う人

同じ年の賃貸不動産経営管理士（11月実施）との併願も選択肢になります。試験日が3週間差で申込締切が同じ日であること、重なる分野と重ならない分野については[賃貸不動産経営管理士と管理業務主任者の併願](/column/chintai-kangyo-hikaku/)で整理しています。

## まず何から始めるか

区分所有法と標準管理規約を先に固めるのが定石です。条文と規約の条番号がそのまま出題の骨格になるので、早く始めるほど反復の回数を稼げます。会計は後回しでも間に合いますが、まったく手をつけないと4問前後を丸ごと失います。

このサイトでは[管理業務主任者の練習問題](/kangyo/)を200問、解説つきで公開しています。通しで時間を計るなら本試験と同じ50問・120分の[模擬試験](/kangyo/moshi/)、短時間で弱点だけ見たいなら20問で分野別の正答率が出る[本番形式テスト](/kangyo/mock/)があります。登録は不要です。

試験日程・受験手数料・免除の要件は年度ごとに変わります。申込の前に必ずマンション管理業協会の公式発表をご確認ください。
