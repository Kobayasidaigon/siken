労働法務士認定試験は、労働関係の法律を総合的に問う認定試験です。全日本情報学習振興協会が実施しています。この記事では、何を問う試験なのか、出題範囲と合格基準、受けるメリットを整理します（2026年11月1日時点、協会の公式案内にもとづきます）。

## どんな試験か

協会は、この試験を「労働基準法、労働契約法、労働組合法、労働安全衛生法、育児・介護休業法などの労働関連法規を総合的に学び、企業や労働者が適切な労務管理を実施するための知識とスキルを認定する試験」と説明しています。

問われるのは、たとえば次のような判断です。

- 36協定を結べば、時間外労働は何時間までさせられるか
- 有期契約を更新してきた社員を、契約期間の満了で雇止めにできるか
- 就業規則を変えて労働条件を下げるには、どんな条件が要るか
- 労働組合からの団体交渉の申入れを、会社は断れるか

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 60問・150分 |
| 合格基準 | 70%以上（問題の難易度により調整し、70%未満でも合格とする場合がある） |
| 受験料 | 一般16,500円／学割13,200円（税込） |
| 追加費用 | CBTは会場費1,500円、オンラインIBTはカメラの往復送料3,000円 |
| 受験方式 | 公開会場（マークシート）・CBT・オンラインIBT |
| 試験日 | 年4回（3月・7月・11月・12月ごろ） |

（出典: 全日本情報学習振興協会「労働法務士認定試験」のページ、2026年10月31日確認）

60問を150分で解くので、1問あたり2分半あります。次回以降の日程は[労働法務士の試験日程](/column/llc-nittei/)にまとめています。

## 出題範囲

協会が示している出題範囲は次の6つです。

| 範囲 | 主な内容 |
|---|---|
| 労働法総論 | 労働法の意義と沿革、憲法上の基本規定（勤労権・団結権など） |
| 雇用関係法 | 労働契約の法理、労働条件の最低基準（労働時間・休日・賃金）、安全と健康、災害補償、人権保障と差別の禁止 |
| 労使関係法 | 労働組合法（団体交渉・労働協約・不当労働行為など） |
| 雇用保障法 | 職業紹介・雇用保険・高年齢者や障害者の雇用など |
| 労働紛争解決のシステム | 労働関係調整法、個別労働紛争の解決（あっせん・労働審判など） |
| その他 | 外国人労働者に関する法規 |

分野ごとの問題数は公表されていません。当サイトでは、雇用関係法を4つの分野に分け、ほかを1つずつにまとめた8分野・各20問の練習問題として並べています。

## 最近の改正に注意する

労働法は改正が続いています。2026年10月時点で押さえておきたいのは次のような点です。

- **時間外労働の上限規制**: 原則月45時間・年360時間。2024年4月から、建設業・自動車運転の業務・医師にも適用
- **労働条件の明示**（2024年4月）: 就業場所・業務の変更の範囲、有期契約の更新上限、無期転換の申込機会の明示
- **育児・介護休業法**（2025年4月・10月）: 子の看護等休暇の見直し、柔軟な働き方を実現するための措置など
- **労働施策総合推進法**（2026年10月1日）: カスタマーハラスメント対策が事業主の措置義務に

教材を選ぶときは、これらの改正に触れているかを1つの目安にしてください。

## 受けるメリット

合格すると、合格証書と写真入りの認定カードが交付され、名刺などに認定ロゴを使えます。協会は、受験をすすめる人として次のような人を挙げています。

- 人事・労務・総務部門の担当者
- 労務管理をする経営者・管理職
- 社会保険労務士を目指す人
- 労働トラブルへの対応に悩んでいる人

社労士試験の労働基準法・労働安全衛生法・労働に関する一般常識と重なる範囲が多く、**社労士の勉強の途中経過を確かめる**目的でも使えます。

関連する試験として、職場のハラスメント対策を扱う[ハラスメントアドバイザー](/had/)、両立支援と働き方を扱う[ワークライフ・コーディネーター](/wlc/)もあります。

## まず何から始めるか

当サイトでは[労働法務士の練習問題](/llc/)を160問、解説つきで無料公開しています。ほとんどの解説で根拠の条文を示しています。最初に、本試験と同じ60問・150分の[模擬試験](/llc/moshi/)で、どの分野が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[腕試しテスト](/llc/mock/)が使えます。登録は不要です。

勉強の進め方は[労働法務士の勉強法と勉強時間](/column/llc-benkyouhou/)、難易度は[労働法務士の合格率と難易度](/column/llc-goukakuritsu/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
