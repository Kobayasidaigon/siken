ワークライフ・コーディネーター認定試験は、60問の試験です。合格基準は公表されていませんが、当サイトでは7割を目安にしています。この記事では、勉強時間の目安と、5つの出題範囲をどの順番で、どう押さえるかをまとめます。

試験の全体像は[ワークライフ・コーディネーター認定試験とは](/column/wlc-toha/)で整理しています。

## 勉強時間の目安

公式の目安は公表されていないので、ここに書くのは当サイトの目安です。

| これまでの経験 | 勉強時間の目安 | 期間の例 |
|---|---|---|
| 人事・労務の実務経験がある、社労士などの勉強をしたことがある | 25〜35時間 | 1日1時間で1か月 |
| 管理職として部下の休業や働き方に関わったことがある | 35〜45時間 | 1日1時間で1か月半 |
| 労働法や社会保険を学んだことがない | 40〜50時間 | 1日1時間で1か月半〜2か月 |

差がつくのは、**子育て・介護と仕事の両立**と**社会保障と税**です。改正が多く、数字で正誤が決まる問題が多い範囲です。

## 教材の選び方

協会の公認テキストがあり、公式サイトから学習資料のページに進めます。テキストの発行時期によっては、2025年以降の改正が入っていません。次の改正は、厚生労働省のリーフレットなどで補ってください。

- 育児・介護休業法の改正（2025年4月・10月施行）
- 雇用保険の出生後休業支援給付・育児時短就業給付（2025年4月）
- 障害者の法定雇用率2.7%（2026年7月から）
- 治療と仕事の両立支援の努力義務化（2026年4月）
- カスタマーハラスメント対策の義務化（2026年10月）

問題演習には、当サイトの[練習問題160問](/wlc/)と、本番と同じ60問の[模擬試験](/wlc/moshi/)が使えます。どちらも無料で、登録は要りません。

## 範囲ごとの進め方

### 1. 労働の基礎知識とワークライフバランス：言葉の定義から

最初に、「仕事と生活の調和（ワーク・ライフ・バランス）憲章」が示す、仕事と生活の調和が実現した社会の3つの姿（就労による経済的自立が可能な社会、健康で豊かな生活のための時間が確保できる社会、多様な働き方・生き方が選択できる社会）を押さえます。働き方改革の考え方や、ダイバーシティ・インクルージョンの用語も、ほかの範囲の問題文に繰り返し出てきます。

### 2. テーマごとのコーディネート：ガイドラインの要点

テレワーク、副業・兼業、フレックスタイム制、長時間労働の防止、健康経営、メンタルヘルス（ストレスチェック）など、厚生労働省のガイドラインや制度の要点を整理します。「会社が義務として行うこと」と「望ましい取組」の区別がよく問われます。

### 3. 両立支援と就労の推進：数字を表にまとめる

いちばん改正が多く、数字が多い範囲です。次のような表を自分で作ると、正誤問題で迷わなくなります。

| 制度 | 押さえる数字の例 |
|---|---|
| 育児休業 | 原則子が1歳まで（保育所に入れないなどの場合は最長2歳まで）、2回まで分割可 |
| 産後パパ育休 | 子の出生後8週間以内に4週間まで、2回まで分割可 |
| 介護休業 | 対象家族1人につき通算93日まで、3回まで分割可 |
| 子の看護等休暇・介護休暇 | 1年に5日（対象が2人以上なら10日） |
| 障害者の法定雇用率 | 民間企業2.7%（2026年7月から） |

治療と仕事の両立支援は、両立支援プランの作り方や、主治医・産業医との情報のやりとりの流れを押さえます。

### 4. 働き方に関する労働法・雇用関係法

労働時間・休日・年次有給休暇、時間外労働の上限規制（原則月45時間・年360時間）、同一労働同一賃金、無期転換、労働条件の明示、ハラスメント対策、解雇・雇止めのルールが中心です。

### 5. 社会保障と税：給付と控除の仕組み

育児休業給付・介護休業給付、傷病手当金、社会保険の適用拡大、公的年金の仕組み、所得税・住民税の控除が中心です。給付率や対象者の要件は、改正のあとの内容で覚えてください。

## 8週間のスケジュール例

1日1時間、労働法や社会保険を学んだことがない人を想定した例です。

| 週 | やること |
|---|---|
| 1週目 | 模擬試験で現在地を確認。労働の基礎知識とワークライフバランスの20問 |
| 2週目 | テーマ別コーディネート①（多様な働き方）の20問 |
| 3週目 | テーマ別コーディネート②（健康とキャリア）の20問 |
| 4週目 | 治療と仕事の両立・障害者就労の20問 |
| 5週目 | 子育て・介護と仕事の両立の20問。数字を表にまとめる |
| 6週目 | 働き方に関する労働法・雇用関係法の40問 |
| 7週目 | 社会保障と税の20問 |
| 8週目 | 間違えた問題を解き直し、模擬試験で7割（42問）以上を確認 |

## まとめ

- 勉強時間の目安は、経験に応じて25〜50時間
- 差がつくのは、子育て・介護と仕事の両立と、社会保障と税
- 改正の多い制度は、施行日と数字を表にまとめて覚える
- 公認テキストに入っていない改正は、厚生労働省の資料で補う

試験日と申込締切は[ワークライフ・コーディネーターの試験日程](/column/wlc-nittei/)で確認できます。練習問題は[こちら](/wlc/)から、[第1問](/wlc/q/wlc-001/)から順に解けます。
