ワークライフ・コーディネーター認定試験は、働き方と生活の両立に関わる知識を問う認定試験です。全日本情報学習振興協会が実施しています。この記事では、何を問う試験なのか、出題範囲と試験の形式、受けるメリットを整理します（2026年11月1日時点、協会の公式案内にもとづきます）。

## どんな試験か

協会は、この試験を「企業経営者や人事担当者のみならず企業で働くひとりひとりの皆さんにも必ず挑戦してほしい試験」と説明しています。働き方改革への理解を深め、職場で両立支援や柔軟な働き方を進める人を育てることがねらいです。

問われるのは、たとえば次のような知識です。

- 育児休業・産後パパ育休や介護休業は、いつ、何日まで取れるか
- テレワークや副業・兼業を認めるとき、会社は何に気をつけるべきか
- 病気の治療と仕事を両立する社員に、会社はどんな配慮ができるか
- 時間外労働の上限や、年次有給休暇の年5日の取得義務
- 育児休業給付や社会保険の適用拡大の仕組み

## 試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | 一般財団法人 全日本情報学習振興協会 |
| 出題形式 | 60問。開催時間は10:00〜11:45 |
| 合格基準 | 協会の案内に記載なし |
| 受験料 | 一般11,000円／学割8,800円（税込）。次回（2027年7月の第11回）から一般14,300円に改定 |
| 追加費用 | CBTは会場費1,500円、オンラインIBTはカメラの往復送料3,000円 |
| 受験方式 | 公開会場（マークシート。東京・名古屋・大阪のみ）・CBT（全国のテストセンター）・オンラインIBT（自宅や会社から） |

（出典: 全日本情報学習振興協会「ワークライフ・コーディネーター認定試験」のページ、2026年10月31日確認）

公開会場は東京・名古屋・大阪の3か所だけです。それ以外の地域の人は、全国のテストセンターで受けるCBTか、自宅や会社のPCで受けるオンラインIBTを選ぶことになります。

次回は2027年7月18日です。日程は[ワークライフ・コーディネーターの試験日程](/column/wlc-nittei/)にまとめています。

## 出題範囲：5つの項目

| 項目 | 主な内容 |
|---|---|
| 1. 労働の基礎知識とワークライフバランスの概念 | 仕事と生活の調和憲章、働き方改革の考え方、ダイバーシティ |
| 2. テーマごとのワークライフ・コーディネート | 非正規雇用の処遇改善、DXの推進、長時間労働の是正、テレワーク・副業・兼業などの柔軟な働き方 |
| 3. 両立支援と就労の推進 | 病気の治療・子育て・介護と仕事の両立、障害者就労、女性活躍、高齢者の就業促進 |
| 4. 働き方に関する労働法 | 労働法の基本、労働契約の成立、ハラスメント対策、労働契約の終了 |
| 5. 雇用関係法と社会保障・税 | 労働基準法・労働契約法、雇用保険・健康保険・公的年金、給与所得者と税 |

項目ごとの問題数は公表されていません。当サイトでは、項目2と項目3と項目5を2つずつの分野に分け、8分野・各20問の練習問題として並べています。

## 合格基準は公表されていない

協会の案内には、合格基準の記載がありません（2026年10月31日確認）。協会のほかの試験の多くは「70%以上」です。当サイトの模擬試験では、7割（60問中42問）を目安として表示しています。

## 改正が多い範囲に注意する

この試験の範囲は、ここ数年で改正が続いています。2026年10月時点で押さえておきたいのは次のような点です。

- **育児・介護休業法**（2025年4月・10月）: 子の看護等休暇の見直し、柔軟な働き方を実現するための措置、介護離職を防ぐための個別の周知・意向確認
- **雇用保険**（2025年4月）: 出生後休業支援給付・育児時短就業給付の創設
- **障害者の法定雇用率**（2026年7月から民間企業は2.7%）
- **治療と仕事の両立支援**（2026年4月から事業主の努力義務）
- **労働施策総合推進法・男女雇用機会均等法**（2026年10月1日）: カスタマーハラスメント対策、求職者へのセクシュアルハラスメント対策

教材を選ぶときは、これらの改正に触れているかを1つの目安にしてください。

## 受けるメリット

合格すると、合格証書と写真入りの認定カードが交付され、名刺などに認定ロゴを使えます。

- 人事・総務の担当者が、両立支援や柔軟な働き方の制度を体系的に確かめられる
- 管理職が、部下の育児・介護・治療と仕事の両立を支えるための知識を身につけられる
- 自分自身のキャリアや家族の状況に合わせて、使える制度を知るきっかけになる

関連する試験として、労働関係の法律を深く問う[労働法務士](/llc/)、職場のハラスメント対策を扱う[ハラスメントアドバイザー](/had/)もあります。

## まず何から始めるか

当サイトでは[ワークライフ・コーディネーターの練習問題](/wlc/)を160問、解説つきで無料公開しています。最初に、本試験と同じ60問の[模擬試験](/wlc/moshi/)で、どの分野が弱いかを確かめると、その後の勉強の順番が決まります。20問で手ごたえだけ見たいときは[腕試しテスト](/wlc/mock/)が使えます。登録は不要です。

勉強の進め方は[ワークライフ・コーディネーターの勉強法と勉強時間](/column/wlc-benkyouhou/)、難易度は[ワークライフ・コーディネーターの合格率と難易度](/column/wlc-goukakuritsu/)で扱っています。

受験料・試験日程・出題範囲は変わることがあります。申込の前に、必ず公式サイトで最新の案内を確認してください。
