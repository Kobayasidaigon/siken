## 解説

### 正解
正解は**選択肢2**です。貸金業者は、貸金業の業務を行うに当たり資金需要者等からの請求があったときは、当該業務を行う営業所又は事務所の貸金業務取扱主任者の氏名を明らかにしなければなりません。

### 各選択肢の解説
#### 選択肢1「従業者は助言を尊重し、指導に従わなければならない」→ ✅
貸金業法第12条の3第2項により、従業者は主任者が行う助言を尊重するとともに、その指導に従わなければなりません。主任者の管理機能を実効的なものにするための規定です。

#### 選択肢2「請求があっても主任者の氏名を明らかにする必要はない」→ ❌
これは不適切な記述です。貸金業者は、貸金業の業務を行うに当たり資金需要者等からの請求があったときは、当該業務を行う営業所又は事務所の貸金業務取扱主任者の氏名を明らかにしなければなりません（貸金業法第12条の3第4項）。

#### 選択肢3「業者は主任者が職務を適切に遂行できるよう配慮する義務」→ ✅
貸金業法第12条の3第2項により、貸金業者は、主任者が助言又は指導に係る職務を適切に遂行できるよう必要な配慮を行わなければなりません。単に主任者を設置すれば足りるのではなく、その機能が発揮できる環境を整えることが求められます。

#### 選択肢4「主任者は法令遵守のための助言・指導を行う義務」→ ✅
貸金業法第12条の3第1項に基づき、主任者は営業所の従業者に対して法令遵守のための助言又は指導を行う義務を負っています。これが主任者の中核的な職務です。

### 背景知識

| 項目 | 内容 |
|------|------|
| 主任者の職務 | 従業者への助言・指導（法令遵守） |
| 従業者の義務 | 主任者の助言を尊重し、指導に従う義務 |
| 業者の義務 | 主任者が職務を適切に遂行できるよう必要な配慮をする義務 |
| 主任者の氏名 | 貸金業者は、資金需要者等から請求があれば明らかにする義務 |
| 根拠条文 | 貸金業法第12条の3 |

主任者制度は、主任者・従業者・貸金業者の三者がそれぞれ義務を果たすことで成り立つ制度です。

### 学習アドバイス
主任者の義務だけでなく、従業者の協力義務や業者の配慮義務まで含めた三者の関係を理解することが重要です。「適切でないもの」を選ぶ問題形式にも慣れておきましょう。

### まとめ
- 従業者は主任者の助言を尊重し、指導に従う義務を負う
- 貸金業者は主任者が適切に職務を遂行できるよう必要な配慮をする義務がある
- 貸金業者は、資金需要者等から請求があれば主任者の氏名を明らかにしなければならない
