## 解説

### 正解
正解は**選択肢4**です。標識は内閣府令で定める様式により掲示する必要があり、デジタルサイネージで代替できるとは法定されていません。

### 各選択肢の解説
#### 選択肢1「登録番号や登録有効期間などが記載される」→ ✅（適切）
標識は内閣府令で定める様式によるもので（貸金業法第23条第1項）、登録番号や登録有効期間などが記載されます。

#### 選択肢2「様式は内閣府令、公衆の見やすい場所に掲示」→ ✅（適切）
貸金業者は、営業所又は事務所ごとに、公衆の見やすい場所に、内閣府令で定める様式の標識を掲示しなければなりません（貸金業法第23条第1項）。

#### 選択肢3「行政処分の対象」→ ✅（適切）
標識の掲示義務に違反した場合、貸金業者は業務改善命令等の行政処分の対象となることがあります。

#### 選択肢4「デジタルサイネージで代替可能」→ ❌（不適切）
標識は、内閣府令で定める様式のものを営業所又は事務所ごとに掲示しなければなりません（貸金業法第23条第1項）。登録情報をデジタルサイネージで表示することにより標識の掲示に代えることができるとする規定はありません。

### 背景知識

| 項目 | 内容 |
|------|------|
| 根拠条文 | 貸金業法第23条 |
| 記載事項 | 登録番号、登録有効期間など |
| 掲示場所 | 営業所又は事務所ごとに、公衆の見やすい場所 |
| 掲示方法 | 内閣府令で定める様式による |

### 学習アドバイス
標識の掲示義務（貸金業法第23条第1項）では、掲示の単位（営業所又は事務所ごと）、掲示場所（公衆の見やすい場所）、様式（内閣府令で定める様式）をあわせて押さえておきましょう。同条第2項では、商号又は名称、登録番号、登録有効期間などを電気通信回線に接続して行う自動公衆送信により公衆の閲覧に供する義務も定められています。

### まとめ
- 標識には登録番号や登録有効期間などが記載される
- 標識は営業所又は事務所ごとに、公衆の見やすい場所に掲示する
- 内閣府令で定める様式で掲示が必要
