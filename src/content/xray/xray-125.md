choices:
  - "A → C → B → D"
  - "B → A → C → D"
  - "A → B → D → C"
  - "A → B → C → D"

correctAnswer: 4
difficulty: "B"

## 解説

正解は4。小腸粘膜は細胞更新が速く、分裂の盛んな腺窩（陰窩）の細胞をもつため感受性が高い。皮膚の表皮は基底層の細胞が分裂しており中等度、肝臓は分裂が少なく比較的低く、神経組織は成熟後ほとんど分裂せず最も低い群に入る。したがってA→B→C→Dとなる。1はBとCが逆で誤り。2はAとBが逆で誤り。3はCとDが逆で誤り。5は感受性の高低を完全に逆にしており誤り。
